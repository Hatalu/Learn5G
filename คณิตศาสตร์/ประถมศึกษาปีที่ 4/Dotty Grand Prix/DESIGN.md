## 2. เป้าหมายการเรียนรู้ (ข้อเสนอของผู้ออกแบบ เพราะผู้ใช้ยังไม่ได้ระบุ)

เมื่อจบบทเรียน นักเรียนสามารถ
1. อ่านและเขียนทศนิยมไม่เกิน 3 ตำแหน่ง จากปริมาณที่กำหนด (แผ่นตาราง 10x10, เส้นจำนวน) และจากคำอ่านได้
2. บอกหลัก ค่าประจำหลัก และค่าของเลขโดดในแต่ละหลักของทศนิยมได้
3. เขียนทศนิยมในรูปกระจาย และเขียนรูปกระจายกลับเป็นทศนิยมได้ (รวมกรณีมีหลักที่เป็น 0)
4. บอกได้ว่าทศนิยมใดเท่ากัน และอธิบายได้ว่าการเติม/ตัด 0 ท้ายทศนิยมไม่ทำให้ค่าเปลี่ยน
5. เปรียบเทียบทศนิยมด้วยเครื่องหมาย > < = และเรียงลำดับจากมากไปน้อย/น้อยไปมาก พร้อมให้เหตุผลทีละหลัก
6. นำความรู้ทั้งหมดไปใช้ในสถานการณ์ใหม่ (การจับเวลาแข่งขัน ที่เวลาน้อยกว่า = ชนะ)

## 3. แนวคิดสื่อ 3 แนวทาง

| แนวทาง | สรุป | จุดแข็ง | ข้อจำกัด |
|---|---|---|---|
| A. แกรนด์ปรีซ์ทศนิยม (เลือกใช้) | เป็นทีมแข่งรถของ "ดอตตี้" รถที่มีจุดทศนิยมเป็นแกนพลัง ผ่าน 5 สนาม แข่งกับเจ้าจุดซนที่ชอบย้ายจุด | บรรยากาศสนามแข่ง + ผู้บรรยายสนาม ตอบโจทย์ "เสียงตื่นเต้น" โดยธรรมชาติ, ทศนิยมพบจริงในการแข่ง (เวลา ระยะ เชื้อเพลิง), การเปรียบเทียบ/เรียงลำดับ = ประกาศอันดับ | ต้องระวังเรื่อง "เวลาน้อยกว่าชนะ" ที่กลับด้านกับ "ระยะมากกว่าชนะ" จึงแยกไว้ในภารกิจสุดท้ายและอธิบายชัด |
| B. ห้องแล็บน้ำผลไม้ | เทน้ำลงบีกเกอร์ 1 ลิตรที่แบ่งขีด 10/100/1000 | เห็นปริมาณชัด | ขีด 1000 ส่วนเล็กมาก อ่านยาก, เรื่องเรียงลำดับไม่เป็นธรรมชาติ |
| C. ร้านขนมชั่งน้ำหนัก | ชั่งน้ำหนักขนมเป็นกิโลกรัม | ใกล้ชีวิตจริง | ความตื่นเต้นน้อยกว่า, รูปกระจาย/ค่าประจำหลักผูกกับเรื่องได้ยาก |

เหตุผลที่เลือก A: ทุกหัวข้อแปลงเป็น "การกระทำในสนามแข่ง" ได้ตรงตัว
- อ่าน/เขียนตามปริมาณ = เติมแผ่นพลังให้ดอตตี้ / จอดรถบนเส้นจำนวน
- หลัก ค่าประจำหลัก รูปกระจาย = ใส่ตัวเลขเข้า "ช่องเกียร์" ตามหลัก / ถอดรหัสประตูพิท
- ทศนิยมที่เท่ากัน = ประตูกระจกแฝดเปิดเมื่อสองฝั่งมีค่าเท่ากัน
- เปรียบเทียบ/เรียงลำดับ = ประลองระยะ / ประกาศอันดับบนโพเดียม
- ภารกิจสุดท้าย = รอบชิงแชมป์ที่ใช้ทุกทักษะในสถานการณ์ใหม่ (จับเวลา)

## 4. ตัวละครและโลกของเรื่อง

- **สนามจุดทอง**: แผนที่สนามแข่ง 5 สนาม เชื่อมด้วยถนนแข่ง ปลดล็อกทีละสนาม มีรถดอตตี้จิ๋วบอกตำแหน่งปัจจุบัน
- **ซิ่งซิ่ง** (ผู้นำทาง/ผู้บรรยายสนาม): เสือชีตาห์ใส่หมวกแก๊ปสีแดง หูฟังมีไมค์ เสื้อทีมสีเขียวมิ้นต์ บุคลิกพลังเยอะ เชียร์เก่ง พูดสั้น กระชับ ชวนเด็กลงมือ ไม่เฉลยทันที ท่าทาง 5 แบบ: ยิ้ม พูด คิด ตกใจ(ว้าว) เชียร์ชูธงตาหมากรุก
- **ดอตตี้** (ตัวแทนผู้เล่น): รถแข่งสีแดงมีตาโตบนกระจก มี "จุดทศนิยมสีทอง" เป็นแกนพลังกลางตัวรถ (สื่อว่าจุดทศนิยมสำคัญ) ล้อหมุน มีควันท่อ มีอารมณ์ ดีใจ ว้าว มึน
- **เจ้าจุดซน** (ตัวสร้างปม ไม่น่ากลัว): ลูกบอลขนฟูสีม่วง มีออร่าซิกแซก ถือจุดสีทองที่ขโมยมา ชอบพูดความเข้าใจผิดที่เด็กพบบ่อย (เช่น "2.45 ยาวกว่าต้องมากกว่า 2.5", "0.05 = 0.5") ให้เด็กพิสูจน์ บางครั้งก็พูดถูก เด็กต้องใช้เหตุผลตัดสินเอง ตอนจบกลับใจมาเข้าทีมช่าง
- **คู่แข่ง**: รถหลากสี มีหมายเลข และ "สายฟ้าฟ้า" คู่ชิงในรอบสุดท้าย

## 5. ลำดับประสบการณ์ (รวมประมาณ 40–50 นาที แนะนำแบ่งเล่น 2–3 คาบ)

| ช่วง | ฉาก | เวลาโดยประมาณ |
|---|---|---|
| เปิดเรื่อง | หน้าแรก + ไฟสตาร์ต 3-2-1-ไป! + แผนที่ + บทนำ (ซิ่งซิ่ง ดอตตี้ เจ้าจุดซน) | 1–2 นาที |
| เรียนรู้วิธีเล่น | ภารกิจฝึกซ้อมข้อแรกของทุกสนาม มีวงแสงชี้ปุ่ม/สอนผ่านการลงมือจริง | แทรกในแต่ละสนาม |
| เรียนรู้เนื้อหา + ภารกิจ | สนาม 1–4 (บทนำพร้อมภาพ + ฝึกซ้อม 3–4 ข้อ + ภารกิจปรับระดับ 5 ข้อ) | 8–10 นาที/สนาม |

| สรุปและจบเรื่อง | หน้าสรุปแต่ละสนาม + โพเดียมแชมป์และใบประกาศความเข้าใจ | 1–2 นาที |

เนื้อหามี 4 หัวข้อใหญ่ จึงเกินกรอบ 15–20 นาที ระบบเก็บความก้าวหน้าระหว่างเปิดหน้าเว็บ (กด "แข่งต่อ" ได้) แนะนำ คาบ 1 = สนาม 1–2, คาบ 2 = สนาม 3–4, คาบ 3 = สนาม 5 + ทบทวน (ครูเปิดโหมดครูเพื่อข้ามไปสนามใดก็ได้)

## 6. รายละเอียดฉากและภารกิจ

### สนาม 1 อู่เติมพลัง — อ่านและเขียนทศนิยมจากปริมาณ
- บทนำ (มีภาพทุกบรรทัด): แผ่นพลังเต็ม = 1 → แบ่ง 10 แถว (ส่วนสิบ 0.1) → แบ่ง 100 ช่อง (ส่วนร้อย 0.01) → ส่องแว่นขยาย 1 ช่องแบ่ง 10 ชิ้นจิ๋ว (ส่วนพัน 0.001) → จุดทศนิยมกะพริบ
- ฝึกซ้อม: เติมพลัง 0.3 (วงแสงชี้ปุ่มแถว) → 0.45 → 1.205 (สอนเลข 0 เก็บหลัก) → เลือกคำอ่าน 0.25 (ตัวลวง "ศูนย์จุดยี่สิบห้า")
- ภารกิจปรับระดับ (วน 5 แบบ): เติมพลังตามตัวเลข / ดูถังพลังแล้วกดตัวเลข / เลือกคำอ่าน / จอดรถบนเส้นจำนวน (ช่วงละ 0.1 → 0.01 → 0.001) / ฟังวิทยุแล้วเขียนตัวเลข
- กลไกพิสูจน์: เติมครบ 10 ชิ้นเล็ก ระบบ "รวมเป็นชิ้นใหญ่" ให้เห็น (10 ส่วนพัน = 1 ส่วนร้อย ฯลฯ)

### สนาม 2 หอเกียร์ — หลัก ค่าประจำหลัก ค่าของเลขโดด รูปกระจาย
- บทนำ: ตารางหลักของ 3.725, ป้ายค่าประจำหลัก 1 / 0.1 / 0.01 / 0.001, เจ้าจุดซนบอก "เลข 4 อยู่ตรงไหนก็เท่ากัน" → ซิ่งซิ่งพิสูจน์ 0.4 ไม่เท่ากับ 0.04
- ฝึกซ้อม: ใส่ตัวเลข 2.47 ลงช่องเกียร์ (แตะหรือลาก) → ใน 5.386 เลข 8 มีค่าเท่าไร → รูปกระจาย 4.275
- ภารกิจ: ประกอบรหัสจากคำใบ้ (ชื่อหลัก / ค่าของเลขโดด / ค่าประจำหลัก, ระดับ 2–3 มีตัวลวงและซ่อนค่าประจำหลัก) / แตะเลขโดดตามหลักหรือตามค่า / ค่าของเลขโดด / รูปกระจาย / รวมรูปกระจายกลับเป็นทศนิยม (ระดับ 3 สลับลำดับ + มีหลักที่เป็น 0)

### สนาม 3 อุโมงค์กระจกแฝด — ทศนิยมที่เท่ากัน
- บทนำ: แผ่นพลัง 0.5 กับ 0.50 ระบายเท่ากันเป๊ะ / เจ้าจุดซนอ้าง 0.05 = 0.5 → แผ่นพลังพิสูจน์ว่าไม่เท่ากัน
- ฝึกซ้อม (เครื่องเติมศูนย์ — การค้นพบ): แตะปุ่ม +0 ตรงตำแหน่งต่าง ๆ ของ 0.7 แล้วดูแผ่นพลัง "ก่อน/หลัง" ว่าเท่ากัน (=) หรือไม่ (≠) แบบสด ๆ → เลือกทุกป้ายที่เท่ากับ 0.4 → ทำ 2.5 ให้เป็น 3 ตำแหน่ง
- ภารกิจ: เลือกป้ายที่เท่ากัน / เครื่องเติมศูนย์ / ประตูกระจก "เท่ากันไหม" / เขียนให้สั้นที่สุด (ตัด 0 ท้าย) / ตัดสินคำพูดของเจ้าจุดซน (ถูกหรือผิด) — ระดับ 3 มีจำนวนนับ (5 = 5.00) และ 0 แทรกกลาง

### สนาม 4 ทางตรงประลองระยะ — เปรียบเทียบและเรียงลำดับ
- บทนำ: ตารางเทียบหลัก 2.45 กับ 2.5 ไฮไลต์ทีละหลัก (เท่ากัน = เขียว, หลักแรกที่ต่าง = เหลืองกรอบแดง) / เจ้าจุดซน "ยาวกว่าต้องมากกว่า" → พิสูจน์
- ฝึกซ้อม: 0.8 ? 0.75 (เปิดตารางเทียบหลักให้ดู) → 3.06 ? 3.6 → เรียง 2.5, 2.45, 2.405 จากมากไปน้อย
- ภารกิจ: เลือกเครื่องหมาย > = < (ตัวลวง: ยาวกว่า, 0 แทรก, เท่ากันเพราะเติม 0, ต่างหลักหน่วย) / เรียงลำดับ 3–5 จำนวน / เลือกรถที่ไกลที่สุดหรือน้อยที่สุด
- กลไกพิสูจน์: หลังตอบถูก (หรือขอคำใบ้ระดับ 2) ตารางเทียบหลักจะไล่ไฮไลต์ทีละหลักให้เห็นเหตุผล

### สนาม 5 แกรนด์ปรีซ์ชิงแชมป์ — ภารกิจสุดท้าย (ประยุกต์ ไม่ใช่ทวนคำถามเดิม)
1. เติมเชื้อเพลิงตามวิทยุ: ใบสั่งมีแต่ "คำอ่าน" ไม่มีตัวเลข (อ่าน → ปริมาณ)
2. ถอดรหัสประตูพิท: รูปกระจายที่สลับลำดับ → ทศนิยม
3. ป้ายเวลารอบสนาม: เลือกทุกป้ายที่เป็นเวลาเดียวกับจอใหญ่ (ทศนิยมที่เท่ากัน)
4. ภาพเส้นชัย: เรียงอันดับจาก "เวลา" (น้อยที่สุด = อันดับ 1 — กลับด้านจากสนาม 4)
5. ผ่านเข้ารอบ: เลือกทุกคันที่ใช้เวลา "น้อยกว่า" เกณฑ์ (ตัวลวง: เท่ากับเกณฑ์พอดี เช่น 1.50 กับ 1.5)
6. รอบชิง 2 จังหวะ: ประกอบเวลาของดอตตี้จากคำใบ้หลัก/ค่า → ตัดสินว่าใครชนะเทียบกับสายฟ้าฟ้า (ดอตตี้อาจแพ้ได้ เด็กต้องตัดสินตามเหตุผลจริง)

### ข้อกำหนดสำหรับอัดเสียงพากย์จริง (อนาคต)

- เจ้าจุดซน: เสียงต่ำกว่า เจ้าเล่ห์ ขี้เล่น มีหัวเราะ "ฮิ ๆ" ไม่ดุ ไม่น่ากลัว
- ทุกบรรทัดสั้น 1–2 ประโยค ตรงกับข้อความบนจอ

## 8. ภาพ แอนิเมชัน และเสียง

- **ภาพ**: SVG วาดด้วยโค้ดทั้งหมด (ไม่มีไฟล์ภาพ ไม่มีอิโมจิ) โทนสนามแข่งสดใส เส้นขอบหนาสีม่วงเข้ม เงาแบบ flat
- **รหัสสีตามหลัก (ใช้ตลอดเกม)**: หน่วย = แดงส้ม, ส่วนสิบ = ส้มเหลือง, ส่วนร้อย = เขียวมิ้นต์, ส่วนพัน = ม่วง, สิบ = ชมพู — ตรงกันทั้งตัวเลข แผ่นพลัง ปุ่มเติม และช่องเกียร์
- **จุดทศนิยม** แสดงเป็นจุดกลมสีแดงขนาดใหญ่ทุกที่ ไม่ให้เด็กมองข้าม
- **แอนิเมชันที่ช่วยอธิบาย**: แผ่นพลังระบายสด ๆ ตามการกด, รวม 10 ชิ้นเป็นชิ้นใหญ่, เครื่องเติมศูนย์เทียบแผ่นก่อน/หลัง, ตารางเทียบหลักไล่ไฮไลต์ทีละหลัก, รถขยับบนเส้นจำนวน
- **Game juice**: ปุ่มเด้งแบบเยลลี่, ดาววิ้ง, เส้นความเร็ว (บูสต์), รถในแถบความคืบหน้าพุ่งไปข้างหน้าเมื่อตอบถูก/ส่ายเมื่อตอบผิด, ไฟสตาร์ต 3-2-1, คอนเฟตตีลายตาหมากรุก
- **เสียงประกอบ (Web Audio สังเคราะห์สด)**: เสียงเครื่องยนต์เร่ง, บูสต์, ล้อเสียดสี, แตรรถ, แอร์ฮอร์น, เสียงกองเชียร์, กลองรัว, บี๊บนับถอยหลัง, ระฆังตอบถูก, เสียงนุ่มเมื่อตอบผิด (ไม่ดุ), เสียงเจ้าจุดซน
- **ดนตรี**: 4 เพลงวนลูป มีกลอง เบส ทำนอง — หน้าแรก (132 BPM สนุกเร้าใจ), แผนที่ (112 BPM สบาย), ระหว่างทำภารกิจ (116 BPM เบาลงเพื่อสมาธิ), รอบชิงแชมป์ (148 BPM ตื่นเต้นสุด) เพลงจะเบาลงอัตโนมัติขณะตัวละครพูด
- **เสียงพากย์แบบตื่นเต้น (ไม่โมโนโทน)**: ใช้เสียงอ่านภาษาไทยของเบราว์เซอร์ (Web Speech API) ร่วมกับ "ระบบน้ำเสียง" ที่ตัดประโยคเป็นวลีตามช่องว่าง แล้วกำหนดระดับเสียงและความเร็วต่อวลีตามอารมณ์ (เชียร์ / ว้าว / ดีใจ / คิด / เจ้าเล่ห์) ไต่ระดับเสียงขึ้นทีละวลี เน้นเสียงสูงท้ายประโยคที่มี "!" และ "?" ตัวละครแต่ละตัวมีระดับเสียงต่างกัน และแปลงตัวเลขทศนิยมเป็นคำอ่านที่ถูกต้องก่อนพูด (0.25 → ศูนย์จุดสองห้า) ปิดได้ในหน้าตั้งค่า

## 9. การโต้ตอบและผลตอบรับ

| เหตุการณ์ | สิ่งที่เกิดขึ้น |
|---|---|
| ตอบถูก | ระฆัง + เสียงเชียร์ + บูสต์, ดาววิ้ง, ตัวเลข +คะแนนลอยขึ้น, รถในแถบความคืบหน้าพุ่งไปข้างหน้า, ซิ่งซิ่งชูธงพร้อมอธิบายสั้น ๆ ว่าทำไมถูก (เช่น "หลักแรกที่ต่างกันคือหลักส่วนสิบ 5 มากกว่า 4") แล้วมีปุ่ม "ซิ่งต่อ!" |
| ตอบผิด | เสียงนุ่ม + รถส่ายเบา ๆ, ไม่ตำหนิ, บอกสิ่งที่เด็กทำได้ตอนนี้ (เช่น "ตอนนี้ได้ 0.4 ยังน้อยไปนิด") หรือวินิจฉัยความเข้าใจผิดเฉพาะ (ลืมจุด / ตก 0 / อ่านหลังจุดแบบจำนวนนับ / ยาวกว่าไม่ใช่มากกว่า / เท่ากับเกณฑ์ไม่ใช่น้อยกว่า) แล้วให้คำใบ้ระดับถัดไป ลองใหม่ได้ทันที |
| ยังไม่ได้ทำอะไร (เช่น กดส่งทั้งที่ยังว่าง) | เตือนเบา ๆ ไม่นับเป็นการตอบผิด |
| ผิด 3 ครั้ง | ปุ่ม "ให้ซิ่งซิ่งช่วย" แสดงคำตอบบนหน้าจอพร้อมเหตุผล ได้ 1 คะแนน และไปต่อได้ |

## 10. ระบบคำใบ้และการปรับความยาก

- **คำใบ้ 3 ระดับ** (ปุ่มหลอดไฟ หรือเกิดเองเมื่อตอบผิด): ระดับ 1 ชวนสังเกต/ทวนหลักการ → ระดับ 2 ชี้เครื่องมือหรือขั้นตอน (เช่น เปิดตารางเทียบหลัก, บอกจำนวนช่องที่ต้องนับ) → ระดับ 3 ชี้เป้าหมายแต่ยังให้เด็กลงมือเอง (ขีดบนเส้นจำนวนกะพริบ, ระบายสีตามหลักให้)
- **เกียร์ (ระดับความยาก) 1–3** ปรับเฉพาะภารกิจหลังช่วงฝึกซ้อม: ทำถูกครั้งแรกโดยไม่ใช้คำใบ้ 2 ข้อติด → เข้าเกียร์สูงขึ้น, ผิด 2 ครั้งขึ้นไปหรือต้องให้ช่วย → ลดเกียร์ ไม่ใช้ความเร็วเป็นเกณฑ์
- เกียร์ 1: ทศนิยม 1–2 ตำแหน่ง ส่วนจำนวนเต็มเล็ก แสดงค่าพลังสด ๆ และป้ายกลางเส้นจำนวน
- เกียร์ 2: 2–3 ตำแหน่ง มี 0 แทรกบ้าง คำใบ้แบบ "มีค่า" ปนกับ "ชื่อหลัก" มีตัวลวง
- เกียร์ 3: 3 ตำแหน่ง มีหลักสิบ, 0 แทรกกลาง, จำนวนนับ (5 = 5.00), ลำดับรูปกระจายสลับ, ซ่อนค่าประจำหลักบนกระดาน, เรียง 5 จำนวนข้ามหลักหน่วย
- ทุกข้อสุ่มใหม่ทุกครั้ง เล่นซ้ำได้ไม่ซ้ำเดิม

## 11. คะแนน ดาว และความก้าวหน้า

- ต่อภารกิจ: ถูกครั้งแรก 3 คะแนน · ใช้คำใบ้/ลองใหม่ 2 คะแนน · ทำสำเร็จได้อย่างน้อย 1 คะแนน (รางวัลความพยายาม)
- ดาวต่อสนาม: 3 ดวง = 85% ขึ้นไป · 2 ดวง = 60% ขึ้นไป · เข้าเส้นชัยได้ 1 ดวงเสมอ (รวม 15 ดวง)
- แผนที่: สนามถัดไปปลดล็อกเมื่อผ่านสนามก่อนหน้า มีธงตาหมากรุกที่สนามที่ผ่านแล้ว รถจิ๋วบอกตำแหน่ง
- แถบความคืบหน้าในสนาม: จุดเช็กพอยต์เปลี่ยนสีทอง/เงิน/ทองแดงตามคะแนนแต่ละข้อ
- ไม่มีการลงโทษ ไม่มีการจับเวลา ไม่มีการเปรียบเทียบกับเด็กคนอื่น

## 13. UX/UI และเว็บไซต์

- รองรับ มือถือแนวตั้ง / มือถือแนวนอน / แท็บเล็ต / คอมพิวเตอร์ และจอสัมผัสหน้าห้อง
  - จอแนวนอน (แท็บเล็ต/คอม): จัดงานแบบซ้าย-ขวา ไม่ต้องเลื่อนจอ
  - มือถือแนวตั้ง: แป้นตัวเลขแบบ 2 แถวเต็มความกว้าง กล่องคำพูดขยายตามข้อความ
  - มือถือแนวนอน (จอเตี้ย): ผู้นำทางย้ายไปแถบซ้าย และย่อเนื้อหาอัตโนมัติให้พอดีจอ
- ปุ่มขนาดนิ้วเด็ก (≥ 44px) แตะได้ทุกอย่าง และลากวางได้ (ตัวเลข/ป้าย) รองรับคีย์บอร์ด (ตัวเลข จุด ลบ Enter)
- ฟอนต์ Mali (ไทย) + Baloo 2 (ตัวเลข) ตัวใหญ่ อ่านง่าย
- ปุ่มลำโพงฟังเสียงพากย์ซ้ำได้ทุกบรรทัด
- หน้าตั้งค่า: ความดัง, เพลง, เสียงพากย์อัตโนมัติ, น้ำเสียงตื่นเต้น, เลือกเสียงพากย์ + ทดลองฟัง, โหมดครู, เริ่มใหม่ทั้งหมด
- สมุดเทคนิคนักซิ่ง: สรุปความรู้แต่ละสนาม เปิดได้เมื่อเล่นสนามนั้นแล้ว
- ความปลอดภัยเด็ก: ไม่มีโฆษณา ไม่มีซื้อของ ไม่มีแชต ไม่มีกล่องสุ่ม เข้าสู่ระบบด้วยบัญชีกลางของโปรเจกต์ (Supabase เหมือนสื่อชิ้นอื่น) ความก้าวหน้าเก็บในเครื่องนั้นเท่านั้น และเริ่มใหม่ทุกครั้งที่เปิดหน้าเว็บ (เครื่องในโรงเรียนใช้ร่วมกัน) จำไว้เฉพาะการตั้งค่าเสียง

## 14. ส่วนที่ทำงานได้จริง / ส่วนที่ยังเป็นตัวอย่าง

ทำงานได้จริง
- ครบ 5 สนาม: บทนำ ฝึกซ้อม 13 ข้อ ภารกิจสุ่ม 26 ข้อต่อรอบ สรุปผล หน้าโพเดียม
- ระบบตรวจคำตอบ คำใบ้ 3 ระดับ วินิจฉัยความเข้าใจผิด ปรับเกียร์ คะแนน ดาว แผนที่ สมุดเทคนิค ตั้งค่า โหมดครู เข้าสู่ระบบ
- SFX / ดนตรี / เสียงพากย์ (ผ่านเสียงอ่านภาษาไทยของเครื่อง) พร้อมระบบน้ำเสียงตื่นเต้น
- ทดสอบแล้ว: ตรรกะสร้างโจทย์ (สร้าง 234,000 ภารกิจทุกระดับ ไม่พบข้อผิดพลาด, ตรวจคำอ่านไทย/ทศนิยมที่เท่ากัน/การเปรียบเทียบ), หน้าจอ 1280x720, 1024x700, 768x1000, 375x812, 844x390

ข้อจำกัด / ยังเป็นตัวอย่าง
- **เสียงพากย์ยังไม่ใช่เสียงคนจริง** เป็นเสียงสังเคราะห์ของเบราว์เซอร์ คุณภาพขึ้นกับเครื่อง แนะนำเปิดด้วย **Microsoft Edge** (มีเสียงไทย Premwadee/Niwat แบบ Natural) หรือ Chrome บนเครื่องที่ติดตั้งภาษาไทย ถ้าเครื่องไม่มีเสียงไทย เกมยังเล่นได้ครบด้วยข้อความ + เสียงประกอบ
- บางเสียงของเบราว์เซอร์อาจไม่รองรับการปรับระดับเสียงสูง-ต่ำ ทำให้ความตื่นเต้นลดลง (ยังมีการแบ่งจังหวะวลี + ดนตรี + SFX ช่วย)
- อนาคต: อัดเสียงพากย์จริงตามข้อกำหนดหัวข้อ 7, รายงานผลรายห้องสำหรับครู, โหมดเล่นเป็นทีมหน้าห้อง
