# โปรโปรซ่อมมุม — สวนสนุกเมืองมุม

เกมการเรียนรู้ คณิตศาสตร์ ป.4 เรื่อง **การวัดและสร้างมุม** (Learn5G Web Games) · พอร์ตทดสอบ 1409
สร้างด้วย HTML5 + SVG ที่วาดด้วยโค้ดทั้งหมด + Web Audio · ไม่มีอิโมจิ ไม่มีโฆษณา ไม่มีแชต ไม่มีสุ่มรางวัล

---

## 1. ข้อมูลที่ได้รับจากผู้ใช้
- วิชา: คณิตศาสตร์ · ระดับชั้น: ป.4 · เรื่อง: การวัดและสร้างมุม
- เนื้อหา: (1) การวัดขนาดของมุมโดยใช้โพรแทรกเตอร์ (2) การสร้างมุมเมื่อกำหนดขนาดของมุม
- คำสั่งเพิ่มเติม: ยกระดับงานภาพให้เป็นสไตล์เด็กประถม สนุกไปกับเกม · สร้างที่ `คณิตศาสตร์/ประถมศึกษาปีที่ 4/การวัดและสร้างมุม/<ชื่อเกม>`
- ผู้ใช้ไม่ได้ระบุผลลัพธ์การเรียนรู้และไม่ได้แนบเอกสาร จึงยึดเฉพาะสองหัวข้อด้านบนเป็นสาระหลัก

**จุดที่ผู้ออกแบบเพิ่มเอง (ไม่ใช่เนื้อหาหลักที่ผู้ใช้กำหนด) — โปรดตรวจ**
1. ชื่อเรียกส่วนของโพรแทรกเตอร์ในเกม: **จุดกึ่งกลาง · เส้นฐาน · สเกลนอก · สเกลใน** เป็นถ้อยคำของผู้ออกแบบ ควรเทียบกับหนังสือเรียนที่โรงเรียนใช้ (บางเล่มเรียก "จุดศูนย์กลาง" หรือ "ขีดบอก 0 องศา")
2. ชนิดของมุม (มุมแหลม มุมฉาก มุมป้าน มุมตรง) ใช้เป็น **ตัวช่วยประมาณก่อนวัดและตรวจคำตอบ** เท่านั้น ไม่ได้สอนเป็นเนื้อหาหลัก (ในโปรเจกต์มีเกมมุมและรูปสี่เหลี่ยมมุมฉาก The Great Map Makers ครอบคลุมเรื่องชนิดของมุมอยู่แล้ว)
3. เกณฑ์ความคลาดเคลื่อนที่ยอมรับ (ดูหัวข้อ 9) กำหนดโดยผู้ออกแบบ

## 2. เป้าหมายการเรียนรู้ (ข้อเสนอของผู้ออกแบบ เพราะผู้ใช้ยังไม่ได้ระบุ)
เมื่อเล่นจบ ผู้เรียนสามารถ
1. บอกส่วนสำคัญของโพรแทรกเตอร์ และอธิบายว่า **องศา** คือหน่วยวัดขนาดของมุม
2. วางโพรแทรกเตอร์ให้ถูกต้อง: จุดกึ่งกลางทับจุดยอดมุม เส้นฐานทับแขนมุมข้างหนึ่ง แขนอีกข้างอยู่ใต้ส่วนโค้ง
3. **วัดขนาดของมุม** โดยเริ่มนับ 0 จากสเกลที่เส้นฐานทับอยู่ (ทั้งแขนฐานด้านขวา ด้านซ้าย และเอียง)
4. **สร้างมุม** ตามขนาดที่กำหนดโดยทำเครื่องหมายบนสเกลฝั่งที่ถูกต้องแล้วลากเส้นจากจุดยอด
5. ตรวจสอบความสมเหตุสมผลของคำตอบ เช่น มุมแคบต้องอ่านได้น้อยกว่า 90° และไม่สับสนสเกลสองฝั่ง (ข้อผิดพลาดที่พบบ่อยที่สุดคือ ได้ 140° แทนที่จะเป็น 40°)

## 3. แนวคิดสื่อ 3 แนวทาง
| แนวทาง | จุดเด่น | ข้อจำกัด |
|---|---|---|
| A. ห้องแล็บวัดมุม (ใบงานดิจิทัลมีแอนิเมชัน) | ตรงเนื้อหา ทำง่าย | เป็นแบบฝึกหัด ไม่สนุก ขัดกับหลักของโปรเจกต์ |
| B. นักสืบมุม (สืบคดีด้วยโพรแทรกเตอร์) | ต่อยอดจาก Shape Detective ได้ | ซ้ำโทนกับเกมเดิม |
| C. **สวนสนุกเมืองมุม — ซ่อมเครื่องเล่นที่ซิกแซกบิดมุม** | เครื่องเล่นแต่ละชิ้นเป็นฉาก ผู้เล่นต้องวัด/สร้างมุมด้วยมือ มีตัวร้ายที่ "อ่านสเกลผิด" ให้จับผิด สีสันสนุกที่สุด | ต้องวาดภาพเยอะ (ทำเป็น SVG ด้วยโค้ดแล้ว) |

**เลือก C** เพราะ "ซ่อมของ" ทำให้การวัด/สร้างมุมเป็นภารกิจจริง และตัวละครซิกแซกทำให้เกิดกิจกรรม "จับผิด" ซึ่งฝึกการตรวจคำตอบ

## 4. ตัวละครและโลกของเรื่อง
- **โปรโปร** (ผู้นำทาง): โพรแทรกเตอร์ครึ่งวงกลมใส ขอบรุ้ง สวมหมวกปาร์ตี้ มีกากบาทแดง (จุดกึ่งกลาง) เป็นสะดือ ร่าเริง ชวนสังเกต ตั้งคำถาม ไม่เฉลยทันที
- **น้องแต้ม** (ตัวแทนผู้เล่น): เด็กหมวกแดง กระโดดดีใจเมื่อทำสำเร็จ เดินไปปักธงบนแถบความคืบหน้า
- **ซิกแซก** (ตัวป่วน ไม่น่ากลัว): ก้อนม่วงมีเสาอากาศหักมุมถือไม้บิด ชอบ "สลับสเกล" แล้วอ้างว่าตัวเองถูก ตอนจบยอมแพ้และขอเรียนด้วย
- **โลก**: สวนสนุกเมืองมุม มีชิงช้าสวรรค์ รุ้ง เต็นท์ลายทาง ลูกโป่งลอย เครื่องเล่น 5 ชิ้นที่ถูกบิดมุม

## 5. ลำดับประสบการณ์ (คาดว่าประมาณ 25–35 นาทีทั้งเกม ยังไม่ได้จับเวลากับเด็กจริง แนะนำแบ่งเล่น 2 คาบ)
เปิดเรื่อง (ล็อกอิน → หน้าแรก → นับถอยหลัง) → แผนที่ + โปรโปรทักทาย → เครื่องเล่น 1–5 (แต่ละชิ้น: ฉากเปิด → ฝึกซ้อมแบบมีคำแนะนำ → ภารกิจปรับระดับ → สรุป/ดาว) → ปราสาทยักษ์ (ภารกิจสุดท้ายแบบประยุกต์) → ฉากจบ ใบประกาศ คำแนะนำฝึกเพิ่ม

## 6. รายละเอียดฉากและภารกิจ
### เครื่องเล่น 1 บูธโปรโปร — รู้จักโพรแทรกเตอร์และองศา
- ฝึก: แตะส่วนต่าง ๆ ตามที่โปรโปรบอก (จุดกึ่งกลาง → เส้นฐาน → สเกลนอก → สเกลใน) · ลากแขนมุมให้เปิดเป็น 90° (มุมฉากมีกรอบเขียวโผล่) และ 180°
- ภารกิจ 4 ข้อ: แขนฐานทับปลายไหน ใช้สเกลไหน · ส่วนที่กะพริบคืออะไร · ประมาณแคบ/กว้างกว่ามุมฉาก · ลากแขนให้ได้ N° (ใช้โพรแทรกเตอร์ใต้แขนเป็นตัวอ่าน)
### เครื่องเล่น 2 รถไฟเหาะสายรุ้ง — วางโพรแทรกเตอร์ให้ถูกที่
- ฝึก: ลากโพรแทรกเตอร์ไปวางเอง (วงเหลืองนำที่จุดยอด ปุ่มสีเหลืองหมุน ดูดเข้าที่เมื่อใกล้)
- ภารกิจ 4 ข้อ: วางบนมุมแขนฐานขวา → ซ้ายหรือเอียง → แขนอีกข้างอยู่ใต้เส้น (ต้องพลิกครึ่งรอบ) → **ใครวางถูก** (เลือกจาก 3 ภาพ เห็นข้อผิดพลาด: จุดกึ่งกลางเลื่อน / เอียง / คว่ำ)
### เครื่องเล่น 3 ชิงช้าหมุนติ้ว — วัดขนาดของมุม
- ฝึก: วัดแบบเลือกคำตอบ (50° แขนฐานขวา · 130° แขนฐานซ้าย โดยมีตัวเลือกลวง 180−ค่า)
- ภารกิจ 5 ข้อ: วัดแบบวางไว้ให้ → วางเอง → แขนฐานซ้ายและเอียง → **ซิกแซกอ้างค่าที่อ่านจากสเกลผิด จริงหรือไม่**
### เครื่องเล่น 4 ปราสาทกระจกวิเศษ — สร้างมุม
- ฝึก: สร้าง 60° (แขนฐานขวา) และ 130° (แขนฐานซ้าย) โดยมีเลของศาขึ้นให้ดู
- ภารกิจ 5 ข้อ: ทำเครื่องหมายแล้วลากเส้น ระดับสูงต้องวางโพรแทรกเตอร์เองบนแขนฐานเอียง ไม่มีเลขช่วย → **ซิกแซกอ้างว่าสร้างมุมได้แล้ว ตรวจดูว่าจริงไหม**
### เครื่องเล่น 5 ปราสาทยักษ์สายรุ้ง — ภารกิจสุดท้าย (ประยุกต์ ไม่ใช่ทวนคำถามเดิม)
- วัดป้ายเบี้ยว · สร้างมุมสไลเดอร์ตามแบบ · ใครวางถูก · **คัดลอกมุม (วัดต้นแบบก่อน แล้วสร้างมุมใหม่ให้เท่ากัน)** · จับผิดซิกแซก · สร้างมุมหลังคาแบบเอียง

## 7. บทพูดหลัก + คีย์เวิร์ดและโทนเสียง
| ตัวละคร | โทนเสียง | ตัวอย่างบทพูด |
|---|---|---|
| โปรโปร | สดใส ตื่นเต้น ไล่เสียงสูงต่ำ | "สวัสดีทุกคน! ฉันโปรโปร โพรแทรกเตอร์ประจำสวนสนุกเมืองมุม!" · "ระวัง! มีเลขสองแถว ต้องใช้แถวที่มีเลข 0 อยู่ตรงแขนฐาน!" |
| ซิกแซก | ต่ำ กวน แต่ไม่น่ากลัว | "ฮิ ๆ ข้าบิดมุมเครื่องเล่นให้เบี้ยวหมดแล้ว!" · ตอนจบ "ก็ได้... ข้ายอมแพ้! ขอเรียนวัดมุมด้วยคนได้ไหม?" |
| ผู้เล่นตอบถูก | ดีใจ | "เป๊ะ! มุมนี้วัดได้ 50 องศา อ่านจากสเกลนอก" |
| ผู้เล่นตอบผิด | ให้กำลังใจ ไม่ตำหนิ | "เกือบแล้ว! ลองอีกนิด" + คำใบ้ตามระดับ |

**ข้อกำหนดเสียงพากย์**: ตอนนี้ใช้เสียงอ่านภาษาไทยของเบราว์เซอร์ (Web Speech) + ระบบน้ำเสียงตื่นเต้น (แบ่งวลี ไล่ระดับเสียง/ความเร็วตามอารมณ์ ไม่โมโนโทน) ตัวเลขและองศาถูกแปลงเป็นคำอ่านไทยก่อนพูด (เช่น 45° → "สี่สิบห้า องศา") **ยังไม่มีไฟล์เสียงพากย์จริง** หากต้องการเสียงอัดจริงให้ใช้บทพูดในไฟล์ `js/stages.js` และ `js/main.js` เป็นสคริปต์ (โปรโปร เสียงเด็กสดใส / ซิกแซก เสียงทุ้มกวน) และปุ่มลำโพงบนกล่องคำพูดจะยังใช้ได้

## 8. ภาพ แอนิเมชัน และเสียง
- **ภาพ**: SVG วาดด้วยโค้ดทั้งหมด (คมทุกขนาดจอ ไม่ต้องโหลดไฟล์ภาพ) · เส้นขอบหนาสีม่วงเข้ม สีสดแบบสติกเกอร์ ไฮไลต์มันเงา · ฉากหลังสวนสนุกเคลื่อนไหว (พระอาทิตย์ยิ้มหมุน ชิงช้าสวรรค์หมุน เมฆลอย ลูกโป่งลอยขึ้น รุ้ง) · เครื่องเล่น 5 ชิ้นเป็นป้ายกลมบนแผนที่ · ปราสาทสายรุ้งพร้อมพลุตอนจบ
- **โพรแทรกเตอร์**: สเกลนอกสีฟ้า สเกลในสีส้ม ตัวเลขหมุนตามแนวรัศมีเหมือนของจริง ขีดทุก 1° 5° 10° เลข 0 ติดป้ายวงกลมสีเดียวกับสเกล · แขนฐานสีฟ้า แขนมุมสีชมพู · วงเรืองแสงชี้เลขที่แขนผ่าน
- **ตัวละคร**: สีหน้าและท่าทางเปลี่ยนตามอารมณ์ (ยิ้ม ตื่นเต้น งง ตกใจ) ขยับตัวหายใจ เดิน กระโดด
- **Juice**: ปุ่มยุบ-เด้งแบบเยลลี่ ดาววิ้ง คลื่นวงกลม ตัวเลขคะแนนลอย ริบบิ้นรุ้ง ลูกโป่งและกระดาษสีโปรย
- **เสียง** (สังเคราะห์สด): ไซโลโฟน กระดิ่งแก้ว แตรปาร์ตี้ เสียงตะไบตอนหมุนโพรแทรกเตอร์ เสียง "คลิก" ตอนดูดเข้าที่ เสียงปากกาลากเส้น กองเชียร์ · เพลงสวนสนุก 4 แบบ (หน้าแรก แผนที่ เล่น ภารกิจสุดท้าย) · เปิด/ปิด/ปรับเสียงได้

## 9. การโต้ตอบและผลตอบรับ
- ลาก/แตะได้ทั้งนิ้วและเมาส์ (Pointer Events) · โพรแทรกเตอร์ลากเลื่อนได้ หมุนด้วยปุ่มสีเหลืองหรือปุ่มลูกศรหมุนละเอียดทีละ 1° (กดค้างได้)
- **ดูดเข้าที่ (magnet)**: ถ้าจุดกึ่งกลางอยู่ห่างจุดยอดไม่เกิน 26 หน่วย จะดูดเข้า แล้วตรวจการหมุนทนได้ ±6°
- **ความคลาดเคลื่อนที่ยอมรับ**: วัดมุม ระดับ 1–2 ต้องตรงเป๊ะ (ค่าเป็นผลคูณของ 10 หรือ 5), ระดับ 3 (ค่าจำนวนเต็มใดก็ได้) ยอม ±1° · สร้างมุม ยอม ±2° (ดึงมาจากข้อเท็จจริงว่าเด็กลากด้วยนิ้วบนจอเล็ก)
- ตอบถูก: เสียง+ดาว+คลื่น อธิบายสั้น ๆ ว่าอ่านจากสเกลไหน
- ตอบผิด: ไม่ตำหนิ วินิจฉัยสาเหตุ เช่น "ได้ 60° ไม่ใช่ 120° ใช้สเกลผิดฝั่งแล้ว" / "จุดกึ่งกลางยังไม่ทับจุดยอด" / "โพรแทรกเตอร์คว่ำอยู่" แล้วต่อด้วยคำใบ้ระดับถัดไป และเปิดให้ลองใหม่ทันที (เส้นที่ลากผิดจะหายไปให้ลากใหม่)

## 10. ระบบคำใบ้และการปรับความยาก
- **คำใบ้ 3 ระดับ** (ปุ่มหลอดไฟ หรือหลังตอบผิด): 1 ชี้ชวนให้สังเกต → 2 บอกวิธีหรือเครื่องมือ → 3 ชี้ตำแหน่งบนภาพ (วงเหลือง / เงาตำแหน่งที่ถูก / ทำเครื่องหมายให้) · ตอบผิดครบ 3 ครั้งมีปุ่ม "ให้โปรโปรช่วย" โปรโปรทำให้ดูแล้วเฉลย
- **ปรับความยาก 3 ระดับ (แถบ "ระดับ")**: ทำถูกครั้งแรกติดกัน 2 ข้อ → ขึ้นระดับ · ผิด 2 ครั้งขึ้นไปหรือขอให้ช่วย → ลงระดับ · **ไม่ใช้ความเร็วเป็นตัวตัดสิน**
  - ระดับ 1: ค่าเป็นผลคูณ 10 แขนฐานแนวนอนเหนือเส้น โพรแทรกเตอร์วางไว้ให้หรือมีวงนำ มีเลขช่วย
  - ระดับ 2: ผลคูณ 5 แขนฐานซ้าย/ขวา/พลิก ไม่มีเลขช่วย
  - ระดับ 3: จำนวนเต็มใดก็ได้ แขนฐานเอียง ต้องวางเอง ไม่มีเงานำ

## 11. คะแนน ดาว และความก้าวหน้า
- ต่อข้อ: ถูกครั้งแรก 3 คะแนน · ใช้คำใบ้/ลองใหม่ 2 · ช่วยกันทำจนสำเร็จ อย่างน้อย 1 (หักตามจำนวนผิด+คำใบ้)
- ดาวต่อเครื่องเล่น: ≥85% = 3 ดวง · ≥60% = 2 ดวง · ผ่านได้ 1 ดวงเสมอ (ไม่มีการลงโทษ ไม่มีเกมโอเวอร์)
- ปลดล็อกเครื่องเล่นถัดไปเมื่อได้อย่างน้อย 1 ดาว · แผนที่แสดงธงเมื่อซ่อมเสร็จ · ดาวรวม 15 ดวง
- เล่นซ้ำได้ทุกเครื่องเล่น เก็บดาวเพิ่ม

## 12. เกณฑ์ประเมินผลการเรียนรู้
ใบประกาศตอนจบแยกเป็น 6 ทักษะ วัดจาก "ทำถูกครั้งแรกโดยไม่ใช้คำใบ้": รู้จักโพรแทรกเตอร์และองศา · วางโพรแทรกเตอร์ให้ถูกที่ · วัดขนาดของมุม · สร้างมุมตามขนาดที่กำหนด · ประมาณและตรวจสอบคำตอบ · นำไปใช้ซ่อมเครื่องเล่น
- ≥80% เข้าใจดีมาก · ≥60% เข้าใจดี · ต่ำกว่า 60% ควรฝึกเพิ่ม พร้อมข้อเสนอแนะรายทักษะ
- โหมดครูแสดงคำถามชวนคิดหลังจบแต่ละเครื่องเล่น

## 13. UX/UI และเว็บไซต์
- Responsive: มือถือแนวตั้ง/นอน แท็บเล็ต คอมพิวเตอร์ · ปุ่มใหญ่ ฟอนต์ Mali/Baloo 2 ข้อความสั้น
- ไม่ต้องเลื่อนจอในฉากเล่น: เนื้อหาย่อสัดส่วนเดียวกันให้พอดีพื้นที่ (ไม่ย่อต่ำกว่า 50%)
- จอกว้างย้ายแถบความคืบหน้าขึ้นแถบบนเพื่อให้พื้นที่วัดมุมใหญ่ขึ้น
- ผู้ใช้เก็บข้อมูลน้อยที่สุด: ไม่มีข้อมูลส่วนตัว เปิดหน้าเว็บใหม่ทุกครั้ง = เริ่มเล่นใหม่ (เก็บเฉพาะค่าตั้งเสียงในเครื่อง)
- **ล็อกอินกลาง Supabase** ตามมาตรฐานโปรเจกต์ (ช่องชื่อผู้ใช้มีข้อความ "ใส่ชื่อที่คุณได้รับมาจากเพจ", dev ไม่จำกัด, member ต้องมี premium_until ที่ยังไม่หมดอายุ)
- 3 โหมด: เล่นตามเรื่อง (ปลดล็อกทีละเครื่อง) · เล่นซ้ำอิสระ (เลือกเครื่องที่ผ่านแล้ว) · โหมดครู (เปิดทุกเครื่อง + คำถามชวนคิด)

## 14. ส่วนที่ทำงานได้จริง / ส่วนที่ยังเป็นตัวอย่าง
**ทำงานได้จริง (ทดสอบแล้ว)**
- ตัวสร้างโจทย์และเรขาคณิตของโพรแทรกเตอร์ผ่านการทดสอบอัตโนมัติ `node tools/test-gen.js` (ตำแหน่งที่ถูก/ผิด/คว่ำ ทุกระดับ แขนฐานทุกทิศ สเกลผิดฝั่ง = 180 − ค่าจริง)
- เล่นผ่านทุกชนิดงานด้วยเบราว์เซอร์จริงผ่านตัวทดสอบอัตโนมัติ: ลากโพรแทรกเตอร์ + หมุนด้วยปุ่ม + พิมพ์ค่า (วัดมุมระดับ 3 แขนฐานเอียง 18/18 ข้อผ่าน) · ทำเครื่องหมาย + ลากเส้น (สร้างมุมทุกระดับ 18/18 ข้อผ่าน) · เส้นทางตอบผิดสเกลแล้วลองใหม่ · รันครบทุกโจทย์ในทุกระดับ 79 ชุดโดยไม่มีข้อผิดพลาด
- หน้าล็อกอิน หน้าแรก แผนที่ ฉากเล่น หน้าสรุป ฉากจบ สมุดบันทึก ตั้งค่า
**ยังเป็นตัวอย่าง / ยังไม่ได้ทดสอบ**
- ยังไม่มีเสียงพากย์อัดจริง (ใช้เสียงอ่านของเบราว์เซอร์ ความเป็นธรรมชาติขึ้นกับเครื่อง)
- ยังไม่ได้ทดสอบบนมือถือ/แท็บเล็ตจริง (ทดสอบด้วยการจำลองขนาดจอในเบราว์เซอร์บนคอมพิวเตอร์เท่านั้น) ควรทดลองกับเด็กจริงก่อนใช้สอน โดยเฉพาะการลากหมุนโพรแทรกเตอร์ด้วยนิ้ว
- การเชื่อมต่อ Supabase จริง ต้องทดสอบด้วยบัญชีของระบบ (ในเครื่องผู้พัฒนาใช้ `?dev=1` ข้ามล็อกอินบน localhost)
- ยังไม่ได้เผยแพร่ขึ้น GitHub Pages

**ฟังก์ชันที่อาจเพิ่มในอนาคต**: เสียงพากย์จริงผ่าน ElevenLabs, โหมดพิมพ์ใบงานมุมจากโจทย์ที่เล่นแล้ว, บันทึกรายงานครูกลาง

## 15. วิธีเปิดใช้งาน
```
node serve1409.js        # เปิด http://localhost:1409  (ทดสอบ: ?dev=1 ข้ามล็อกอินบน localhost)
node tools/test-gen.js   # ทดสอบตัวสร้างโจทย์/เรขาคณิต
```
ตัวช่วยทดสอบเมื่อเปิดด้วย `?dev=1`: `APdev.preview(เครื่องเล่น, ระดับ, ลำดับ)` (ลำดับติดลบ = ฝึกซ้อม) · `APdev.solve()` · `APdev.fakeFinish(เครื่องเล่น, [คะแนน...])` · `APdev.showFinal()`
