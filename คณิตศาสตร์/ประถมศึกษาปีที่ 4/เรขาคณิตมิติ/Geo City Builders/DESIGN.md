# ปิ๊งช่างเรขา กู้เมืองเส้นตรง! (Geo City Builders)
คณิตศาสตร์ ป.4 · เรื่อง รูปเรขาคณิต · เวลาเล่นประมาณ 18–22 นาที

## 1. ข้อมูลที่ได้รับจากครู
- วิชา: คณิตศาสตร์ / ระดับชั้น: ป.4 / หัวข้อ: รูปเรขาคณิต
- เนื้อหา: ระนาบ จุด เส้นตรง รังสี ส่วนของเส้นตรง และสัญลักษณ์ · มุม (ส่วนประกอบ การเรียกชื่อ สัญลักษณ์ ชนิด) · ชนิดและสมบัติของรูปสี่เหลี่ยมมุมฉาก · การสร้างรูปสี่เหลี่ยมมุมฉาก
- เงื่อนไข: เสียงตัวละครจาก ElevenLabs, เกมมี motion/เอฟเฟกต์/แอนิเมชัน

## 2. เป้าหมายการเรียนรู้ (ข้อเสนอของทีม ตามเนื้อหาที่ครูให้)
หลังเล่นจบ นักเรียนสามารถ
1. บอกความหมายของระนาบและจุด และจำแนกเส้นตรง รังสี ส่วนของเส้นตรง จากจำนวนจุดปลาย
2. เขียนและอ่านสัญลักษณ์ของเส้นตรง รังสี ส่วนของเส้นตรง (รังสีต้องเขียนจุดปลายก่อน)
3. บอกส่วนประกอบของมุม เรียกชื่อมุมโดยให้จุดยอดอยู่ตรงกลาง และเขียนสัญลักษณ์มุม
4. จำแนกมุมแหลม มุมฉาก มุมป้าน มุมตรง มุมกลับ จากขนาดของมุม
5. ตรวจสอบสมบัติและจำแนกรูปสี่เหลี่ยมจัตุรัส/ผืนผ้า/ไม่ใช่สี่เหลี่ยมมุมฉาก พร้อมเหตุผล
6. สร้างรูปสี่เหลี่ยมมุมฉากตามความยาวด้านที่กำหนด

## 3. แนวคิด 3 แบบที่พิจารณา
| แนวคิด | จุดเด่น | เหตุที่ไม่เลือก/เลือก |
|---|---|---|
| A. นักสืบเรขาคณิต (ไขคดี) | สนุกแนวลึกลับ | ซ้ำกับ Shape Detective (ป.2) |
| B. ยานอวกาศจัดเส้นทางดาว | ภาพสวย | การ "สร้างรูป" ไม่เป็นธรรมชาติกับเนื้อเรื่อง |
| **C. ช่างซ่อมเมืองที่ถูกลบ (เลือก)** | ทุกความรู้ = เครื่องมือช่างจริง: ลากสะพาน (ส่วนของเส้นตรง) ฉายไฟประภาคาร (รังสี) วางราง (เส้นตรง) ตั้งเครน (มุม) ตรวจชิ้นงาน (สมบัติ) และสร้างลาน (การสร้าง) | เนื้อหาทั้ง 4 ส่วนกลายเป็นกลไกเกมโดยตรง และมีเป้าหมายชัด (ซ่อมเมืองคืน) |

## 4. ตัวละครและโลก
- **ปิ๊ง** หุ่นยนต์ช่างหมวกเหลือง เสาอากาศเป็น "จุด" เรืองแสง หน้าอกมีเครื่องหมายมุมฉาก ร่าเริง ชวนสังเกต ไม่เฉลยตรง ๆ (เสียง Jessica – สดใส)
- **ลบลบ** ยางลบจอมซน ลบเส้นทั้งเมือง ไม่น่ากลัว ตอนจบกลับใจมาช่วยสร้างเมือง (เสียง Laura – ซน ๆ)
- **นายช่างน้อย** = ผู้เล่น
- โลก: เมืองเรขาในสไตล์ "พิมพ์เขียวการ์ตูน" ตึกที่ถูกลบเป็นเส้นประ เมื่อผ่านย่านจะกลับมามีสี

## 5. ลำดับประสบการณ์
หน้าแรก → เปิดเรื่อง (ลบลบลบเมือง) → แผนที่เมือง 7 ย่าน (ปลดล็อกทีละย่าน) → ป้ายเปิดย่าน → ภารกิจ → (เล่นดี → ภารกิจท้าทายพิเศษ) → สรุปย่าน (ดาว/สิ่งที่ได้เรียนรู้) → ย่าน 7 ด่านลบลบ (ภารกิจประยุกต์) → ตอนจบ → หน้าสรุปรวม + คำแนะนำฝึกเพิ่ม

## 6–10. รายละเอียดย่าน ภารกิจ การโต้ตอบ และผลตอบรับ
| ย่าน | ภารกิจ (กลไก) | ตอบถูก | ตอบผิด |
|---|---|---|---|
| 1 ลานจุดและเส้น | แตะวางจุดบนระนาบ · ลากสะพาน A→B แล้วเลือกปลายเส้น (ส่วนของเส้นตรง) · ไฟประภาคาร P ผ่าน Q (รังสี ต้องลากจากจุดปลาย) · รางรถไฟ M–N (เส้นตรง) · คัดป้ายเข้ากล่องตามจำนวนจุดปลาย | สะพานไม้ต่อขึ้นทีละแผ่น / ลำแสงพุ่ง / รถไฟวิ่งผ่าน + อธิบายชื่อเส้น | บอกผลของการเลือก เช่น "รังสียาวต่อไป สะพานจะยื่นลงทะเล" |
| 2 สถานีป้าย | พลิกป้ายดูสัญลักษณ์ · ประกอบป้ายจากกระเบื้อง (เครื่องหมาย + ตัวอักษร) · เลือกรูปที่ตรงกับ "รังสี KL" | ป้ายเขียวเรืองแสง | ตรวจละเอียด: ผิดเครื่องหมาย / รังสีกลับลำดับ |
| 3 หอคอยมุม | หมุนรังสีให้เกิดมุม → แตะจุดยอดและแขน · แตะจุดเรียงชื่อมุม (มีจุดหลอก) · ประกอบสัญลักษณ์มุม | ชื่อมุมกลายเป็นสัญลักษณ์ ∠ | "จุดยอดต้องอยู่ตรงกลาง" / "จุดนี้ไม่อยู่บนแขนของมุม" |
| 4 สวนสนุกมุม | หมุนแขนเครน/ประตู/สไลเดอร์/กระดานหก/ชิงช้าสวรรค์ ให้ได้มุมฉาก แหลม ป้าน ตรง กลับ (มีตัวเลของศา) · คัดมุมเข้าเครื่องเล่น | เครื่องเล่นทำงาน | "ตอนนี้ได้ X องศา เป็นมุม… ต้องการ…" |
| 5 โรงงานสี่เหลี่ยม | ใช้ตัวเช็กมุมฉาก + ไม้บรรทัด ตรวจ 6 ชิ้นงาน แล้วประทับตรา จัตุรัส/ผืนผ้า/ไม่ใช่ (มีรูปหมุนเอียง รูปสี่เหลี่ยมขนมเปียกปูน รูปมุมฉากสองมุม) | ตราประทับใหญ่ | ต้องมีหลักฐานก่อนตัดสิน (ตรวจมุมครบ/วัดด้านครบ) |
| 6 อู่สร้างเมือง | สร้างผืนผ้า 6×3 และจัตุรัส 4×4 ตามขั้นตอน (ไม้บรรทัด → ไม้ฉาก → ไม้ฉาก → เชื่อม) · สร้างเองบนกระดานจุด (5×2, จัตุรัส 3) | เครื่องหมายมุมฉากขึ้นครบ 4 มุม | บอกความยาวที่ได้ / มุมไหนไม่ใช่มุมฉาก |
| 7 ด่านลบลบ | 6 ภารกิจในสถานการณ์ใหม่ (ไฟส่อง, มุมบนหอ, เครน, ประตูปลอม 95°, ลาน 4×2, คำถามพร้อมเหตุผล) | พลังลบลบลดลง | เหมือนข้างบน |

## 11. คำใบ้และการปรับความยาก
- คำใบ้ 3 ระดับ (ปุ่มหลอดไฟ): สังเกต → ใช้ตัวช่วย (ไฮไลต์จุด/แผนภูมิช่วงองศา) → ชี้ชัด (กล่อง/ตรากระพริบ, เส้นนำ) โดยเด็กยังต้องลงมือเอง
- ผิดครั้งที่ 2–3 ระบบเปิดตัวช่วยให้อัตโนมัติ (ลดความซับซ้อน)
- ย่านที่ผิดไม่เกิน 1 ครั้ง → เสนอ "ภารกิจท้าทายพิเศษ" (รังสีกลับทิศ, มุมเกือบ ๆ 80/100/170/195°, รูปผืนผ้ายาวพิเศษ, สนาม 7×4) ไม่บังคับ และไม่ใช้ความเร็วตัดสิน

## 12. คะแนน ดาว ความก้าวหน้า
- ต่อภารกิจ: ไม่ผิด 3 / ผิด 1 ครั้ง 2 / ผิดมากกว่า 1 (ได้ 1 เสมอ) · ใช้คำใบ้ระดับ 3 ได้ไม่เกิน 2
- ดาวย่าน: ≥90% = 3 ดาว, ≥65% = 2, ที่เหลือ 1 · ผ่านภารกิจท้าทายได้ถ้วยพิเศษ · ทำผิดแล้วสำเร็จได้ "เหรียญพยายาม"
- แผนที่: ตึกที่ซ่อมแล้วกลับมามีสีพร้อมดาว ย่านถัดไปปลดล็อก

## 13. เกณฑ์ประเมิน (ครูดูได้ในโหมดครู)
ดาว + จำนวนครั้งที่ตอบผิด + ระดับคำใบ้ต่อย่าน → ย่านที่ได้ < 3 ดาวหรือผิด ≥ 3 ครั้ง แสดงเป็น "ควรฝึกเพิ่ม" ในหน้าสรุป

## 14. UX/UI และเว็บไซต์
- Mobile-first: แนวตั้ง (กระดานบน แผงควบคุมล่าง) / แนวนอน (กระดานซ้าย แผงขวา) · ปุ่มใหญ่ ≥ 48px · รองรับนิ้วและเมาส์
- ภาพทั้งหมดเป็น SVG ไม่มีไฟล์รูป ไม่มีอิโมจิ · SFX/BGM สังเคราะห์ด้วย Web Audio
- เสียงพากย์: ไฟล์ ElevenLabs ใน `audio/voice/` · ถ้าไม่มีไฟล์ จะใช้เสียงอ่านภาษาไทยของเบราว์เซอร์แทน · ปุ่มลำโพงฟังซ้ำ/ฟังคำอธิบาย
- ตั้งค่า: ความดัง, เพลง, เสียงพากย์, โหมดครู, เริ่มใหม่ · เปิดเว็บใหม่ = เริ่มใหม่ (เก็บเฉพาะการตั้งค่า) · ล็อกอิน Supabase กลาง
- สมุดช่าง: สรุปความรู้ทุกย่านพร้อมภาพ

## 15. ส่วนที่ทำงานจริง / ส่วนที่ยังต้องทำ
- ทำงานจริง: ทุกย่าน ทุกภารกิจ คำใบ้ คะแนน แผนที่ สรุป ตอนจบ โหมดครู ล็อกอิน
- เสียง ElevenLabs: สร้างแล้ว 35 จาก 92 ประโยค (ดู `js/voiced.js`) ที่เหลือใช้เสียงเบราว์เซอร์ชั่วคราว
  สร้างส่วนที่เหลือได้ด้วย `node tools/elevenlabs-generate.js` (ต้องมี API key)
- ฟังก์ชันอนาคต: บันทึกผลส่งครูผ่านระบบกลาง, ภารกิจวัดมุมด้วยไม้โปรแทรกเตอร์
