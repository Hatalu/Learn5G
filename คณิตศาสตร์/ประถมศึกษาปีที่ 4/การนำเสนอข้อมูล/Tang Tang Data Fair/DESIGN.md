# แท่งแท่ง ตะลุยงานวันข้อมูล! (Tang Tang Data Fair)
คณิตศาสตร์ ป.4 · เรื่อง การนำเสนอข้อมูล · เวลาเล่นประมาณ 18–22 นาที

## 1. ข้อมูลที่ได้รับจากครู
- วิชา: คณิตศาสตร์ / ระดับชั้น: ป.4 / หัวข้อ: การนำเสนอข้อมูล
- เนื้อหา: (1) การอ่านและการเขียนแผนภูมิแท่ง (ไม่รวมการย่นระยะ) (2) การอ่านตารางสองทาง (two-way table)
- ที่ตั้ง: `คณิตศาสตร์/ประถมศึกษาปีที่ 4/การนำเสนอข้อมูล/Tang Tang Data Fair/`
- หมายเหตุขอบเขต: แกนตั้งของแผนภูมิเริ่มที่ 0 เสมอและไม่มีสัญลักษณ์ย่นระยะ ตามที่ครูกำหนด ตารางสองทางสอนในรูปแบบ "อ่าน" (หาช่อง ผลรวม เปรียบเทียบ เติมค่าที่หายไป) ไม่ได้สอนให้เขียนตารางเอง

## 2. เป้าหมายการเรียนรู้ (ข้อเสนอของทีม ตามเนื้อหาที่ครูให้)
หลังเล่นจบ นักเรียนสามารถ
1. บอกส่วนประกอบของแผนภูมิแท่ง (ชื่อแผนภูมิ แกนนอน แกนตั้ง แท่ง) และอ่านค่าของแท่งจากแกนตั้ง
2. เปรียบเทียบข้อมูลจากแผนภูมิ: มากที่สุด/น้อยที่สุด ผลต่าง ผลรวม การเรียงลำดับ และตัดสินข้อความจริง/ไม่จริง
3. บอกได้ว่าแกนตั้งนับทีละเท่าไร และอ่านค่าแท่งที่ยอดอยู่ระหว่างช่อง (เช่น ช่องละ 10 ยอดแท่งอยู่ที่ 35)
4. เขียนแผนภูมิแท่งจากข้อมูลที่กำหนด: เลือกช่องแกนตั้งที่เหมาะสม ตั้งชื่อแผนภูมิ/แกน และสร้างแท่งให้สูงถูกต้อง
5. อ่านตารางสองทาง: หาช่องที่แถวกับหลักตัดกัน หาผลรวมแถว/หลัก/ทั้งหมด ตอบคำถามเปรียบเทียบ และหาค่าที่หายไป
6. เชื่อมโยงตารางสองทางกับแผนภูมิแท่ง (สร้างแผนภูมิจากผลรวมของแต่ละหลัก)

## 3. แนวคิด 3 แบบที่พิจารณา
| แนวคิด | จุดเด่น | เหตุที่เลือก/ไม่เลือก |
|---|---|---|
| A. นักสืบข้อมูล (ไขคดีด้วยแผนภูมิ) | ลึกลับ น่าติดตาม | ซ้ำแนวกับ Shape Detective (ป.2) และการ "สร้างแผนภูมิ" ไม่เป็นธรรมชาติ |
| B. ร้านค้าจำลอง (เก็บสถิติขายของ) | ใกล้ตัว | คล้าย Punpun Pie Shop (เศษส่วน ป.4) |
| **C. งานวันข้อมูล (เลือก)** | ทุกซุ้มในงานคือทักษะหนึ่ง: นับ-อ่านแท่ง, เปรียบเทียบ, หาช่อง, โรงงานสร้างแท่ง, ตารางสองทาง ตัวละคร "แท่ง" ยืดสูงต่ำได้จริง | เนื้อหาทั้งสองส่วนกลายเป็นกลไกเกมโดยตรง และมีเป้าหมายชัดเจน (กู้งานที่ถูกทำมั่ว) |

## 4. ตัวละครและโลก
- **แท่งแท่ง** เสาแท่งสีส้ม มีขีดแกนตั้งข้างตัว ผ้าพันคอสีเขียวน้ำทะเล ใบอ่อนบนหัว ร่าเริง ชวนสังเกต ไม่เฉลยตรง ๆ ตัวยืด-หดตามอารมณ์ (squash & stretch)
- **มึนมึน** เมฆม่วงตาก้นหอย ชอบทำข้อมูลมั่ว ไม่น่ากลัว ตอนจบสำนึกผิดและมาช่วยจัดงาน
- **ผู้ช่วยนักสำรวจ** = ผู้เล่น
- โลก: งานวัดสดใส มีธง ซุ้มลายทาง ถนนดินโรยกรวด ซุ้มที่ยังไม่กู้จะเป็นสีเทา กู้เสร็จกลับมามีสีพร้อมดาว

## 5. ลำดับประสบการณ์
หน้าแรก → (ล็อกอิน) → เปิดเรื่อง (มึนมึนทำซุ้มมั่ว) → แผนที่งาน 6 ซุ้ม (ปลดล็อกทีละซุ้ม) → ป้ายเปิดซุ้ม → ภารกิจ → (เล่นดี: ภารกิจท้าทายพิเศษ / พลาดเยอะ: ซ้อมเพิ่ม) → สรุปซุ้ม (ดาว สิ่งที่ได้เรียนรู้) → ซุ้ม 6 ด่านมึนมึน → ตอนจบ → หน้าสรุปรวม + คำแนะนำฝึกเพิ่ม

## 6–10. รายละเอียดซุ้ม ภารกิจ การโต้ตอบ และผลตอบรับ
ข้อมูลทุกภารกิจสุ่มใหม่ทุกครั้งที่เล่น (ชุดข้อมูลแผนภูมิ 6 ชุด / ตารางสองทาง 4 ชุด) แต่ตรวจคำตอบจากข้อมูลจริงเสมอ

| ซุ้ม | ภารกิจ (กลไก) | ตอบถูก | ตอบผิด |
|---|---|---|---|
| 1 ลานนับนับ | แตะส่วนประกอบของแผนภูมิ · แตะเลขบนแกนตั้งที่ตรงกับยอดแท่ง · แตะแท่งที่มาก/น้อยที่สุด · แกนตั้งนับทีละ 2 | ส่วนที่แตะเรืองแสง + อธิบายสั้น ๆ | บอกว่าที่แตะคืออะไร แล้วให้ลองใหม่ |
| 2 ร้านเปรียบเทียบ | มากกว่ากี่ · รวมกันเท่าไร · จริง/ไม่จริง · แตะเรียงแท่ง (ขึ้นเลขอันดับ) · ช่องละ 5 | ประกาย + สมการสั้น ๆ เช่น 8 − 5 = 3 | บอกให้เทียบค่าของแท่งทีละแท่ง |
| 3 ลานหาช่อง | แกนตั้งนับทีละเท่าไร (เลขสองช่องเรืองแสง) · ช่องละ 5 · ยอดแท่งอยู่ระหว่างช่อง (ช่องละ 10) · ช่องละ 20 · หาแท่งที่สูง N | บอกวิธีอ่านค่ากึ่งกลางช่อง | ชี้ว่าให้ดูช่องที่ติดกัน / กึ่งกลางคือครึ่งหนึ่ง |
| 4 โรงงานสร้างแท่ง | ตั้งชื่อแผนภูมิและแกน · แตะ/ลากแท่งให้สูงตามตาราง (snap เข้าเส้น) · เลือกช่องแกนตั้งจากตัวอย่าง 3 แบบ · แก้แท่งที่มึนมึนแอบแก้ผิด | ตรวจแล้วแท่งทุกแท่งตรงกับตาราง | บอกชื่อแท่งที่ยังไม่ตรง (ไม่บอกค่า) |
| 5 ร้านตารางสองทาง | หาช่องที่แถวตัดหลัก · อ่านค่าในช่อง · เติมผลรวมด้วยแป้นตัวเลข · ถามจากตาราง (รวมแถว/หลัก มากสุด ผลต่าง) · หาตัวเลขที่หายไป | ช่องเปลี่ยนเป็นสีเขียว + บอกที่มา | แสดงแถว/หลักของช่องที่แตะ ให้เทียบกับโจทย์ |
| 6 ด่านมึนมึน | อ่านแผนภูมิหลายขั้น · อ่านตารางหลายขั้น · ตารางเป็นแผนภูมิ (สร้างจากผลรวมแต่ละหลัก) · แท่งนี้ตรงกับช่องไหนในตาราง · จริง/ไม่จริง · หาตัวเลขที่หายไป 3 ช่อง | พลังมึนมึนลด | เหมือนข้างบน |

## 11. คำใบ้และการปรับความยาก
- คำใบ้ 3 ระดับ (ปุ่มหลอดไฟ) แยกตามข้อ: ระดับ 1 บอกวิธีสังเกต → ระดับ 2 ตัวช่วยบนภาพ (เส้นประจากยอดแท่งไปแกนตั้ง, ไฮไลต์แถว/หลัก, ธงแดงที่แท่งที่ผิด) → ระดับ 3 ชี้ชัด (ตัดตัวเลือกผิด 2 ข้อ, เลขเรืองแสง, สมการให้เติม) โดยเด็กยังต้องลงมือเอง
- ตอบผิดซ้ำ 2 และ 3 ครั้งในข้อเดียวกัน ระบบเปิดคำใบ้ระดับ 2 และ 3 ให้อัตโนมัติ (ลดความซับซ้อน)
- ซุ้มที่ผิดรวมไม่เกิน 1 ครั้ง → เสนอ "ภารกิจท้าทายพิเศษ" (ไม่บังคับ) · ผิดรวม ≥ 4 ครั้ง → เสนอ "ซ้อมเพิ่มอีกข้อ" แบบสบาย ๆ (ไม่นับคะแนน)
- ไม่ใช้ความเร็วตัดสิน ไม่มีนับเวลา ไม่มี Game Over

## 12. คะแนน ดาว ความก้าวหน้า
- ต่อภารกิจ: ไม่ผิด 3 / ผิด 1–2 ครั้ง 2 / ผิดมากกว่านั้น 1 (ได้อย่างน้อย 1 เสมอ) · ใช้คำใบ้ระดับ 3 ได้ไม่เกิน 2
- ดาวซุ้ม: คะแนน ≥ 90% = 3 ดาว, ≥ 65% = 2, ที่เหลือ 1 · ภารกิจท้าทายได้ถ้วยพิเศษ · ทำผิดแล้วสำเร็จได้ "เหรียญพยายาม"
- แผนที่: ซุ้มที่กู้แล้วกลับมามีสีพร้อมดาว ซุ้มถัดไปปลดล็อก

## 13. เกณฑ์ประเมิน (ครูดูได้ในโหมดครู)
ดาว + จำนวนครั้งที่ตอบผิด + จำนวนภารกิจที่ใช้คำใบ้ระดับ 3 ต่อซุ้ม → ซุ้มที่ได้ < 3 ดาวหรือผิด ≥ 3 ครั้ง แสดงเป็น "ควรฝึกเพิ่ม" ในหน้าสรุป · โหมดครูมีคำถามชวนคิดท้ายแต่ละซุ้ม

## 14. UX/UI และเว็บไซต์
- Mobile-first: แนวตั้ง (กระดานบน แผงคำถามล่าง) / แนวนอน (กระดานซ้าย แผงขวา) · ปุ่มใหญ่ ≥ 48px · รองรับนิ้วและเมาส์ · ลากแท่งใช้ pointer events (ไม่เลื่อนหน้าจอขณะลาก)
- ภาพทั้งหมดเป็น SVG/CSS ไม่มีไฟล์รูป ไม่มีอิโมจิ · SFX/BGM สังเคราะห์ด้วย Web Audio
- เสียงพากย์: ถ้ามีไฟล์ `audio/voice/<id>.mp3` เล่นไฟล์นั้น ไม่เช่นนั้นใช้เสียงอ่านภาษาไทยของเบราว์เซอร์ (เมื่อเครื่องมีเสียงไทย) ไม่ได้ก็เงียบและยังเห็นข้อความ · ปุ่มลำโพงฟังซ้ำ · ตั้งค่า: ความดัง เพลง เสียงพากย์ โหมดครู เริ่มใหม่
- เปิดเว็บใหม่ = เริ่มใหม่ (เก็บเฉพาะการตั้งค่า) · ไม่มีโฆษณา ไม่มีแชต ไม่มีการสุ่มรางวัล · ล็อกอิน Supabase กลาง (หน้าล็อกอินมีข้อความ "ใส่ชื่อที่คุณได้รับมาจากเพจ")
- สมุดแท่งแท่ง: สรุปความรู้ของแต่ละซุ้มพร้อมแผนภูมิ/ตารางตัวอย่าง

## 15. ส่วนที่ทำงานจริง / ส่วนที่ยังต้องทำ
- ทำงานจริง: ทุกซุ้ม ทุกภารกิจ (4 กลไก) คำใบ้ 3 ระดับ ปรับความยาก คะแนน แผนที่ สรุป ตอนจบ โหมดครู ล็อกอิน
- ทดสอบแล้ว: เล่นอัตโนมัติครบทั้ง 6 ซุ้มจนถึงตอนจบโดยไม่มี error ใน Browser · สุ่มโจทย์ 31,600 ข้อตรวจเงื่อนไข (ตัวเลือกไม่ซ้ำ มีคำตอบ ค่ามากสุด/น้อยสุดไม่เสมอ เส้นแกนตั้ง 4–12 เส้น ค่าอยู่บนเส้นหรือกึ่งกลางช่อง ตารางไม่มีค่าซ้ำในแถว/หลัก) ไม่พบปัญหา · ตรวจรูปแบบหน้าจอมือถือแนวตั้งและจอกว้าง
- ยังไม่ได้ทดสอบ: การลากแท่งด้วยนิ้วบนอุปกรณ์สัมผัสจริง (ทดสอบด้วย pointer events จำลอง) และเสียงอ่านภาษาไทยบนเครื่องที่ไม่มีเสียงไทย
- เสียงพากย์: **ยังไม่มีไฟล์เสียงพากย์จริง** (ElevenLabs) บทพูดตายตัว 32 ประโยคอยู่ใน `js/lines.js` (มีแท็กอารมณ์พร้อมส่ง) สร้างได้ด้วย `node tools/elevenlabs-generate.js` (ต้องมี API key) แล้วรัน `node tools/build-voiced.js` · ประโยคโจทย์/คำอธิบายที่เปลี่ยนตามข้อมูลสุ่มใช้เสียงอ่านของเบราว์เซอร์เสมอ
- ฟังก์ชันอนาคต: ส่งผลให้ครูผ่านระบบกลาง, ภารกิจเขียนตารางสองทางเอง, ข้อมูลจริงจากห้องเรียน
