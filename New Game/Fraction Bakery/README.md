## เนื้อหา 6 เมนู + ด่านพิเศษ
| เมนู | สอน (บทเรียนในตัว) | เด็กทำอะไร |
|---|---|---|
| 1 แบ่งให้เท่ากัน | เศษส่วนต้องแบ่งเท่ากัน (จิ๊ดจิ๊ดตัดไม่เท่าให้ดู) | แตะเค้กที่แบ่งเท่ากัน / กดมีดตัดให้ได้จำนวนชิ้นตามลูกค้า |
| 2 อ่านและเขียนเศษส่วน | ตัวล่าง = ทั้งหมด, ตัวบน = ที่เลือก | แต่งครีมตามออเดอร์ / อ่านเค้กว่าเป็นเศษส่วนเท่าไร |
| 3 เศษส่วนของกลุ่ม | 2/3 ของ 6 = 2 จาน = 4 ชิ้น | หยิบคุกกี้ใส่กล่อง |
| 4 เปรียบเทียบ | ส่วนเท่ากัน / เศษเท่ากัน (แก้ความเชื่อผิด "ตัวล่างมาก = ใหญ่") | แตะเค้กที่ครีมมากกว่า หรือ "เท่ากัน" |
| 5 เศษส่วนที่เท่ากัน | กดมีดผ่าเพิ่ม 1/2 → 2/4 → 4/8 | แต่งครีมเค้กชิ้นเล็กให้เท่าเค้กต้นแบบ |
| 6 บวกลบ (ส่วนเท่ากัน) | บวก/ลบเฉพาะตัวเศษ, จิ๊ดจิ๊ดกินเค้ก = ลบ | แต่งครีมผลลัพธ์ |
| พิเศษ ออเดอร์ใหญ่ | ทบทวนรวม | 6 ข้อจากคลังกลาง `createDeck('math', 3/4, 'fraction3'/'fraction4')` |

## ระบบ
- **Adaptive**: ถูกรอบแรก 2 ข้อติด ระดับขึ้น (ส่วน 2–4 → 3–6 → 5–10), ผิด ระดับลง
- **Soft feedback**: ผิดครั้งแรก = คำใบ้ + ตัดตัวเลือกผิด/เรืองแสงกลุ่มที่ใช่, ผิดครั้งที่สอง = มิมิสาธิตคำตอบแล้วไปต่อ ไม่มี Game Over
- **ตัวป่วน**: จิ๊ดจิ๊ดชี้ตัวเลือกผิดพร้อมพูดชวนเชื่อ (สอนให้ตรวจเอง), แอบโผล่มาขโมย — แตะทันได้ +3 เหรียญ, ไม่ทันก็ไม่เสียอะไร (มี cooldown)
- **รางวัลข้ามรอบ**: เหรียญ → ซื้อของแต่งร้าน 6 ชิ้น (กันสาด ดอกไม้ ไฟประดับ ลูกโป่ง เค้กยักษ์ สายรุ้ง) ร้านบนหน้าแผนที่เปลี่ยนตาม
- **ดาว 1–3** ต่อเมนู, ปลดล็อกเมนูถัดไปเมื่อผ่าน, หน้าสรุปบอกทุกข้อว่าถูกรอบแรกหรือต้องฝึกเพิ่ม
- เสียง: เสียงตัวละคร 36 คลิปใหม่ + 26 คลิปจากคลังกลาง `AI Voice/`, ถ้าไฟล์โหลดไม่ได้ใช้เสียงอ่านของเบราว์เซอร์แทน; SFX + BGM จาก Web Audio
- บันทึกใน localStorage (`fraction-bakery-v1`)
- คีย์บอร์ด: Enter = เสิร์ฟ/ต่อไป, 1–3 = เลือกตัวเลือก
- dev hook: `FB.solve()` ตอบข้อปัจจุบันถูก, `FB.startChapter(i)`
