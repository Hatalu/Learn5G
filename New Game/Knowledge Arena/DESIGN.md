# Knowledge Arena — สนามประลองรอบรู้

เกมปาร์ตี้ 3D บนเกาะลอยฟ้า 2–4 คน ทุกคนแย่งกันเก็บคะแนน 3–5 นาที คะแนนหลักมาจาก "ตอบคำถามความรู้รอบตัวถูก" ส่วนการชน/แย่งวงเป็นสีสัน
เล่นได้ทุกวัย (เลือกช่วงวัยต่อผู้เล่น) ไม่มีโฆษณา ไม่มีล็อกอิน ไม่มีแชต ไม่มีอิโมจิ

## วิธีรัน
- `node "New Game/serve1111.js"` (หรือ launch config `new-game-1111`) แล้วเปิด `http://localhost:1111/Knowledge%20Arena/`
- ทดสอบตรรกะเกมแบบไม่ใช้จอ: `node "New Game/Knowledge Arena/tools/simtest.mjs"` (แมตช์บอท 4 ตัว 3 นาที ต้องได้ `ok`)
- ทดสอบห้องออนไลน์: `node "New Game/Knowledge Arena/tools/nettest.mjs"` (2 client ส่งข้อความหากัน ต้องได้ `ok`)
- ตรวจคลัง: `node "New Game/คลังข้อมูลเนื้อและโจทย์/tools/validate.mjs"` ต้องได้ "ผิด 0"

## Game Concept
| หัวข้อ | รายละเอียด |
|---|---|
| ชื่อ | Knowledge Arena / สนามประลองรอบรู้ |
| One-line | ปาร์ตี้ประลองบนเกาะลอยฟ้า แตะลูกแก้ว "?" ตอบคำถามรอบตัว ตอบถูกได้คะแนนก้อนใหญ่ + สกิลพิเศษ |
| ธีม | Floating Island Arena: เกาะหญ้า ต้นซากุระ หินมอส คริสตัล บ่อน้ำผึ้ง เห็ดเด้ง น้ำตก เกาะเล็กลอยรอบๆ ทะเลเมฆ |
| เป้าการเรียนรู้ | ความรู้รอบตัว 5 หมวด: วิทยาศาสตร์รอบตัว, สัตว์และธรรมชาติ, ภูมิศาสตร์, ประวัติศาสตร์, ชีวิตประจำวัน |
| Core loop | เมนู -> ตัวละคร -> (การ์ดความรู้ก่อนลงสนาม) -> นับถอยหลัง -> เดินเก็บดาว/เพชร, ภารกิจ, ยึดวงมงกุฎ, ชนคู่แข่ง -> แตะลูกแก้ว ? = คำถาม -> รางวัล -> หมดเวลา -> โพเดียม + อันดับ + ทบทวน -> เล่นอีกครั้ง |
| ตัวละคร | "บัดดี้" chibi 3D: สี 8 สี x หู 4 แบบ (แมว กระต่าย หมี จิ้งจอก มีหางต่างกัน) x หมวก 6 แบบ (ปลดล็อกด้วยดาว) |
| Audio | Web Audio สังเคราะห์ทั้งหมด (pop, กระดิ่งแก้วตอนตอบถูก, เสียงชน, นับถอยหลัง, BGM 4 คอร์ดเร่งจังหวะตอนแข่ง) ไม่มีเสียงก็เล่นได้ |

## ระบบ
### การเคลื่อนที่/ต่อสู้ (`js/sim.js`)
- เดิน 8 ทิศ + แอนะล็อก (จอยลอยบนจอสัมผัส), พุ่งหลบ (ไร้ตัวตน 0.22 วิ คูลดาวน์ 1.1 วิ), ชน (กรวยหน้า 1.9 ม. กระเด็น + มึน 0.45 วิ)
- ใจดีกับเด็ก: คนเดิมโดนคนเดิมชนซ้ำได้ทุก 1.1 วิเท่านั้น, ตกเกาะ = เกิดใหม่ใน 1.3 วิ ไม่เสียคะแนน ไม่เสียสกิล, มีอมตะ 2.2 วิหลังเกิด
- ระหว่างตอบคำถามอยู่ในฟองโล่ (หยุดเดิน แต่ไม่มีใครชนได้)
- อุปสรรค: หิน ต้นไม้ คริสตัล (ชนแล้วไถลออก), บ่อน้ำผึ้ง (ช้าลงครึ่งหนึ่ง), เห็ดเด้ง 2 จุด (ดีดออก), ขอบเกาะมีเส้นเรืองแสง + เสาไฟให้เห็นชัด

### ความรู้ (หัวใจของเกม)
- ลูกแก้ว ? 6 จุด (ติดพร้อมกันประมาณ 3) เกิดใหม่ทุก 7–12 วิ, มีลูกศรม่วงชี้ลูกแก้วที่ใกล้สุด (ขอบจอเมื่ออยู่นอกจอ)
- คำถามปรนัย 3 ตัวเลือก จากคลังกลาง `createDeck('general', ช่วงวัย, หมวด)` วนหมวดที่เลือกไว้
- ช่วงวัยต่อผู้เล่น: ป.1–3 (ระดับ 1–2), ป.4–6 (1–3), ม.ต้นขึ้นไป (2–3), ผู้ใหญ่ (2–3) — คนต่างวัยเล่นห้องเดียวกันได้ ใครวัยไหนได้ข้อของวัยนั้น
- Adaptive: ถูก 2 ข้อติด ขึ้นระดับ / ผิดจบข้อ ลงระดับ (อยู่ในกรอบของช่วงวัย)
- ตอบผิดครั้งแรก: ตัดตัวเลือกนั้นออก + คำใบ้ (ไม่บอกคำตอบ) ให้ลองใหม่ (ได้คะแนนครึ่งเดียว)
- ผิดครั้งที่สอง/หมดเวลา: โชว์เฉลยสั้น ("คำตอบ — เหตุผล") ไม่มีบทลงโทษอื่น
- ถูก: 100/120/150 ตามระดับ + สกิลสุ่ม 1 อย่าง (ถ้าช่องสกิลเต็มได้ +20 แทน)
- สกิล: วิ่งเร็ว 6 วิ, โล่ฟอง (กันชน 2 ครั้ง), คลื่นกระแทก (ผลักทุกคนรอบตัว), แม่เหล็กดูดดาว 8 วิ, แต้มคูณสอง 10 วิ (ดาว/เพชร/วงมงกุฎ)
- สอนก่อนเล่น: หน้า "ความรู้ก่อนลงสนาม" การ์ด 1 ใบต่อหมวดที่เลือก (เปิดเป็นค่าเริ่มต้น ข้ามได้ ปิดได้ในหน้าตั้งค่า) + "การ์ดความรู้" จากเมนู (ครบทุกการ์ด 5 หมวด ตามช่วงวัย)
- หลังจบ: รายการทุกข้อที่ตอบ ข้อผิดมีเฉลย + ปุ่ม "การ์ด" เปิดการ์ดบทเรียนที่ตรงที่สุด (`lessonFor`)
- ข้อยกเว้นจากสูตร New Game: ไม่บังคับอ่านบทเรียนทั้งบทก่อนเล่น เพราะเป็นเกมปาร์ตี้หลายหมวดหลายวัย ใช้การ์ดอุ่นเครื่องแทน (ปิดได้)

### แหล่งคะแนน (ชนะ = คะแนนสูงสุดตอนหมดเวลา)
| แหล่ง | คะแนน |
|---|---|
| ตอบถูก | 100 / 120 / 150 (ลองครั้งที่สอง ครึ่งเดียว) |
| ดาว / เพชร | 10 / 25 (x2 ระหว่างแต้มคูณสอง) |
| ภารกิจส่วนตัว (หมุนเวียน 5 แบบ) | 40–80 ต่อภารกิจ |
| ยึดวงมงกุฎคนเดียว | 4 ต่อวิ (มีคนแย่ง = ไม่มีใครได้), วงย้ายที่ทุก 40 วิ |
| ประลอง | ชน +5, ผลักตกเกาะ +20 — **รวมไม่เกิน 150 ต่อแมตช์** |
- แมตช์บอททดสอบ: คะแนนความรู้ ~60–75% ของทั้งหมด, ประลองไม่เกิน ~7% คนที่ตั้งใจตอบไม่เสียเปรียบคนชอบชน (simtest ตรวจว่าความรู้ > ประลอง x2)

### บอท
- เลือกเป้าหมายตามคะแนนความสำคัญ (ลูกแก้ว > เพชร > วงมงกุฎ > ดาว) สลับโหมดดุ/สงบสุ่มๆ หลบอุปสรรค บ่อน้ำผึ้ง ขอบเกาะ
- ตอบคำถามหลังคิด 2–5 วิ ความแม่น ~62–77% ยากขึ้นแม่นน้อยลง ใช้สกิลเมื่อได้

### ออนไลน์ (Create/Join Room)
- **Supabase Realtime Broadcast** ช่องสาธารณะ `realtime:ka-<รหัส 5 ตัว>` ผ่าน WebSocket ตรง (Phoenix vsn 1.0.0, `js/net.js` ~60 บรรทัด ไม่ต้องลงไลบรารี ไม่ใช้ตารางฐานข้อมูล) ใช้ URL + anon key ชุดสาธารณะเดียวกับเกม Learn5G อื่นที่ฝังในหน้าเว็บอยู่แล้ว
- โฮสต์เป็นเจ้าของเกม: รัน `sim.js` ทั้งหมด (รวมบอท) ส่ง snapshot 10 ครั้ง/วิ + เหตุการณ์ ผู้เล่นอื่นส่งแค่ปุ่ม (ไม่เกิน ~14 ครั้ง/วิ) และคำตอบ
- เฉลยอยู่ที่โฮสต์ ผู้เล่นได้แค่คำถาม+ตัวเลือก (เฉลยส่งหลังตอบจบข้อ)
- ห้องรอ: 4 ช่อง เพิ่ม/เอาบอทออก, เลือกเวลา, ผู้เล่นใหม่เข้าแทนบอทได้, ใครหลุดเกิน 8 วิ บอทเล่นแทน
- สีซ้ำกับคนในห้อง โฮสต์เปลี่ยนให้เป็นสีที่ยังว่างอัตโนมัติ (ทุกคนหน้าตาไม่ซ้ำกัน)
- `tools/nettest.mjs` ต่อ Supabase โปรเจกต์จริงทุกครั้งที่รัน (ใช้ช่องชั่วคราว ไม่เขียนฐานข้อมูล)
- ชื่อผู้เล่นเป็นชื่อสุ่ม (สัตว์+คำน่ารัก) ไม่มีช่องพิมพ์ข้อความ = ไม่มีแชต ไม่มีข้อมูลส่วนตัว

### ออฟไลน์
- เล่นกับบอท 1–3 ตัว (ครบแมตช์คนเดียวได้)
- 2 คนเครื่องเดียว (คีย์บอร์ด): P1 WASD / F ชน / G พุ่ง / R สกิล / ตอบ 1 2 3, P2 ลูกศร / Enter / Shift ขวา / `/` / ตอบ 8 9 0 + บอทเพิ่ม 0–2 ตัว กล้องซูมตามระยะห่างสองคน การ์ดคำถามแยกซ้าย/ขวา

### ของสะสมข้ามรอบ
- ดาว = จำนวนข้อถูก + โบนัสอันดับ (5/3/2/1) เก็บใน localStorage `ka_v1` ใช้ปลดล็อกหมวก (ดอกไม้ 20, มงกุฎ 60, ใบพัด 120, วงแหวนดาว 200)

### ภาพและความรู้สึก (`js/arena.js`)
- three.js r170, MeshToon 4 ระดับแสง + เส้นขอบ inverted hull, เงาแบบ blob (ไม่ใช้ shadow map เพื่อมือถือ), DPR สูงสุด 1.5 (เครื่องแรมน้อย 1 + ปิด antialias)
- บัดดี้ยืดหดตอนวิ่ง (squash & stretch) แกว่งแขนขา หาง ท่าชน มึนมีดาวหมุน ฟองโล่ ฟอง ? ตอนตอบ ออร่าตอนสกิล กระพริบตอนอมตะ
- อนุภาค: ประกายเก็บดาว, ควันปุ๊งตอนชน, พลุตอนตอบถูก, ฝุ่นพุ่ง, คอนเฟตติโพเดียม; กล้องสั่นเบาๆ, กล้องเลื่อนนุ่ม (ไม่ตัดฉาก) + fade ระหว่างหน้าจอ
- ปุ่มเยลลี่ขอบหนาเงาทึบ ยุบ-เด้งทุกครั้งที่กด, ป้ายคะแนนลอย "+10", ธง/ภารกิจมีแถบความคืบหน้า

## Dev hook (`window.KA`)
`KA.useInterval()` (แผงเบราว์เซอร์ที่ซ่อนอยู่หยุด rAF), `KA.startBots({bots, dur, local})`, `KA.botMe(true)` (ให้ AI เล่นแทนเรา), `KA.run(วินาที)` (เร่งเวลาโดยไม่วาด), `KA.toOrb()` (วาร์ปไปลูกแก้ว เปิดคำถาม), `KA.quiz()`, `KA.answer(true|false)`, `KA.screen()`, `KA.me()`

- iPad (จำลอง 768x1024 + บังคับโหมดสัมผัส): ปุ่ม/จอย/การ์ดคำถามอยู่ในจอ ไม่ล้นแนวนอน

- สแกนอิโมจิ: ไม่พบ; console ไม่มี error

## ยังไม่ได้ทดสอบ / ข้อจำกัด
- เครื่องจริง (มือถือ/แท็บเล็ต) ความลื่นและความร้อน, เสียงจริง (เครื่องทดสอบไม่มีลำโพง), สัมผัสหลายนิ้วพร้อมกัน (จอย + ปุ่ม)
- ออนไลน์: ทดสอบในเครื่องเดียว 2 แท็บ ยังไม่เคยลอง 4 เครื่องบนเน็ตมือถือ; โฮสต์ต้องเปิดแท็บเกมค้างไว้ (สลับแท็บ/ปิดจอ = เกมหยุด เพราะเบราว์เซอร์หยุดวาด), โฮสต์ออก = ห้องปิด; ใช้โควตา Realtime ของโปรเจกต์ Supabase เดียวกับเว็บหลัก (ยังไม่ได้วัดว่าหลายห้องพร้อมกันไหวแค่ไหน); ไม่มีระบบกันโกงฝั่งโฮสต์ (โฮสต์แก้คะแนนตัวเองได้)
