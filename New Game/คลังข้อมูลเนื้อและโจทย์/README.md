## ภาพประกอบบทเรียน (`v`)
เกมเป็นคนวาดเอง (Sky Rally: `js/visuals.js`) คลังเก็บแค่สเปก:
| type | ฟิลด์ | ใช้กับ |
|---|---|---|
| `numberline` | from, to, step, mark | เส้นจำนวน |
| `blocks` | hundreds, tens, ones | หลักร้อย สิบ หน่วย |
| `place` | digits | ตารางค่าประจำหลัก |
| `compare` | left, op, right | มากกว่า น้อยกว่า |
| `frac` / `fraccompare` | n, d / a, b, eq | แถบเศษส่วน |
| `clock` / `dial` / `ruler` / `scale` | h, m / value, max, unit / len, mm / left, right, heavy | การวัด |
| `groups` / `longdiv` / `coins` / `picto` / `bars` / `pie` / `grid100` / `table` | ดูในไฟล์บทเรียน | คูณ หาร เงิน ข้อมูล ร้อยละ |
| `shapes` / `angle` / `rect` / `box` / `lines` / `circle` / `tree` / `ratio` | ดูในไฟล์บทเรียน | เรขาคณิต |
| `pairs` / `flow` / `letters` | rows / steps, cycle / text | คำศัพท์คู่ความหมาย ลำดับขั้น วัฏจักร |
| `plant` `magnets` `particles` `moon` `planets` `forces` `circuit` `eclipse` `prep` `arrows` | ตามไฟล์ | ภาพวิทย์และอังกฤษเฉพาะเรื่อง |

## เชื่อมโจทย์กับบทเรียน
`lessonFor(topic, question)` คืนการ์ดบทเรียนที่ตรงกับโจทย์ข้อนั้นมากที่สุด (เทียบตัวอักษรคู่ เพราะภาษาไทยไม่เว้นวรรค) ใช้ตอนเด็กตอบผิด เพื่อพากลับไปทบทวนส่วนที่เกี่ยวข้อง

## อ้างอิงหลักสูตร
- คณิตศาสตร์และวิทยาศาสตร์: หลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน พ.ศ. 2551 (ฉบับปรับปรุง พ.ศ. 2560) — ตัวชี้วัดและสาระการเรียนรู้แกนกลางรายชั้น
- ภาษาอังกฤษ: กลุ่มสาระภาษาต่างประเทศของหลักสูตรเดียวกัน หลักสูตรกำหนดเป็นมาตรฐาน/ตัวชี้วัด ไม่ได้กำหนดหัวข้อคำศัพท์รายชั้น หัวข้อในคลังจึงเรียงตามคำศัพท์และไวยากรณ์ที่ใช้สอนทั่วไปในแต่ละชั้น
- การจัดเรื่องลงชั้นทำตามความเข้าใจของผู้จัดทำ ควรให้ครูตรวจเทียบกับหนังสือ สสวท. อีกรอบก่อนใช้จริง

## วิธีใช้ในเกม
```js
import { SUBJECTS, GRADES, LEVELS, listTopics, getTopic, createDeck, lessonFor } from '../คลังข้อมูลเนื้อและโจทย์/index.js';
const topic = getTopic('math', 4, 'fraction4');    // topic.lesson = การ์ดเต็มบท

const topics = listTopics('math', 4);              // [{ id, name }]
const deck = createDeck('math', 4, 'fraction4');   // { topic, next(d) }
const q = deck.next(2);                            // d: 1 เริ่มต้น | 2 ฝึกฝน | 3 ท้าทาย
// q = { q, a, choices: [3 ตัวเลือกสลับแล้ว], answer: index, hint, explain, d }
```
- `deck.next(d)` ไม่ซ้ำข้อจนกว่าจะหมดคลัง ถ้าระดับนั้นหมดจะหยิบระดับใกล้เคียง
- `createDeck(..., { choices: 4 })` ขอ 4 ตัวเลือกได้ (คณิตส่วนใหญ่มีตัวลวงพอ)
- เศษส่วนเขียนเป็น `3/4`, จำนวนคละ `2 1/3` — เกมแสดงเป็นเศษส่วนซ้อนเอง

## เพิ่มโจทย์
- วิทย์/อังกฤษ: เพิ่มแถว `[d, 'คำถาม', 'คำตอบถูก', ['ตัวลวง1', 'ตัวลวง2'], 'คำใบ้']`
- คณิต: แก้ฟังก์ชัน `gen(d, r)` ของหัวข้อ (ใช้ `r.int`, `r.pick` จาก `util.js` เพื่อให้สุ่มซ้ำได้)
- ตัวเลือกยาวไม่เกิน 26 ตัวอักษร (ต้องพอดีป้ายในเกม) ห้ามอิโมจิ
