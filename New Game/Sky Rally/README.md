# Sky Rally ซิ่งฟ้าสายรุ้ง

เกมแข่งรถ 3D บนรางสายรุ้งลอยฟ้า เล่นได้ทุกวิชา (คณิต วิทย์ อังกฤษ) ป.1–ป.6 ทุกเรื่องในคลังโจทย์กลาง

## รัน
```bash
node "New Game/serve1111.js"
```
เปิด http://localhost:1111/ (เด้งไป `/Sky%20Rally/`) — หรือใช้ launch config `new-game-1111`

## วิธีเล่น
เลือกรถ > วิชา > ชั้น > เรื่อง > ความยาก > การ์ดบทเรียนสั้น > แข่ง
- รถวิ่งเอง โจทย์ขึ้นแผงบน ป้ายคำตอบ 3 ป้ายแขวนเหนือ 3 เลน (สีชมพู/เหลือง/ฟ้า ตรงกับปุ่มคำตอบ)
- เปลี่ยนเลน: แตะปุ่มคำตอบ, ปุ่มลูกศรซ้ายขวา, ปัดจอ, คีย์ ซ้าย/ขวา A/D หรือ 1/2/3
- ชะลอ: ปุ่มชะลอ ค้างไว้ / ลูกศรลง / S — ไว้มีเวลาคิด
- ลอดป้ายถูก: คริสตัลระเบิด + บูสต์ แซงคู่แข่ง
- ลอดป้ายผิด: ไม่ตาย มีควันปุ๊งแล้วช้าลงเล็กน้อย ข้อเดิมกลับมาที่ประตูถัดไปพร้อมคำใบ้ และตัวเลือกที่ผิดถูกขีดฆ่า
- 8 ประตูต่อรอบ มีดาวให้เก็บ แผ่นบูสต์ และเช็กพอยต์
- จบรอบ: อันดับ ดาว 1–3 (ตามความแม่นครั้งแรก + อันดับ) และรีวิวทุกข้อพร้อมคำอธิบาย

## บทเรียนก่อนแข่ง
- สอนครบทุกส่วนของบท (5–8 การ์ด) มีแถบสารบัญให้กดข้ามไปส่วนไหนก็ได้ ส่วนที่อ่านแล้วขึ้นสีเขียว
- การ์ดมีภาพประกอบวาดด้วย SVG (แถบเศษส่วน นาฬิกา บล็อกหลัก วัฏจักร คู่คำศัพท์ ฯลฯ) และปุ่มอ่านให้ฟัง
- ฝึกก่อนแข่ง 2 ข้อ: ตอบผิดจะบอกว่าควรทบทวนส่วนไหน (กดแล้วกลับไปการ์ดนั้น)
- ระหว่างแข่ง ตอบผิดแล้วคำใบ้จะชี้ส่วนของบทเรียนที่เกี่ยวข้อง และหน้าผลมีปุ่ม "ทบทวนส่วนที่ ..." ทุกข้อที่ผิด

## ไอเทมและการแกล้ง
- กล่อง ? เรียงทุกเลนในสนาม ตอบถูกก็ได้ไอเทมด้วย (อันดับท้ายได้ไอเทมดีกว่า)
- จรวดเทอร์โบ, โล่ฟองสบู่, ลูกบอลดาว (ยิงคันข้างหน้า), เยลลี่ลื่น (วางข้างหลัง), เมฆฝน (ทุกคันข้างหน้าช้าลง), แม่เหล็กดาว
- คู่แข่งใช้ไอเทมใส่เราได้ แต่มีช่วงพัก 9 วินาทีหลังโดน ไม่ให้เด็กโดนรัว โดนแล้วแค่หมุนติ้ว 1 วินาที
- ปุ่มไอเทมกลางล่าง / Space / E / ลูกศรขึ้น

## อู่แต่งรถ
- เก็บดาว + ตอบถูกครั้งแรกข้อละ 5 + โบนัสอันดับ = ดาวไว้แต่งรถ (บันทึกถาวร)
- เครื่องยนต์ (เร็วขึ้น 4%/ขั้น), ไอพ่นบูสต์ (นานขึ้น 20%/ขั้น), แม่เหล็กดูดดาว, โล่ตอนออกตัว

## ระบบ
- 3 โลกตามวิชา: คณิต = Rainbow Sky, วิทย์ = Jungle Temple, อังกฤษ = Crystal City (สนามคนละรูปทรง)
- ความยากปรับเอง: ถูกติดกัน 2 ข้อ ขึ้นระดับ, ผิด ลดระดับ; ความเร็วตามชั้นและระดับ; คู่แข่งใช้ rubber band
- โมเดล 3D สร้างด้วยโค้ด (toon shading + เส้นขอบ): คนขับ chibi หูแมว แว่นกันลม รถมีล้อเรืองแสง ท่อไอพ่น ไฟใต้ท้อง เลือกได้ 4 คัน
- เสียง: Web Audio สังเคราะห์ทั้งหมด (BGM, เครื่องยนต์, เสียงถูก/ผิด/บูสต์/เหรียญ) ปุ่มอ่านโจทย์ใช้เสียงของเบราว์เซอร์ (ถ้ามีเสียงภาษาไทย)
- บันทึก: IndexedDB (schema v1 + migration) ถ้าใช้ไม่ได้จะใช้ localStorage แล้ว memory — เก็บดาว/อันดับ/เวลาดีสุดต่อเรื่อง, รถที่เลือก, เปิดปิดเสียง
- ไม่มีโฆษณา ไม่มี login ไม่มีอิโมจิ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `js/main.js` | ลำดับหน้าจอ กติกาตอบคำถาม ปรับความยาก HUD อินพุต |
| `js/race.js` | โลก 3D สนาม ประตูคำตอบ รถ AI เอฟเฟกต์ กล้อง |
| `js/models.js` | โมเดลรถ คนขับ เกาะลอยฟ้า คริสตัล เมฆ |
| `js/audio.js` | เสียงทั้งหมด + อ่านโจทย์ |
| `js/save.js` | บันทึกความคืบหน้า |
| `js/rich.js` | แสดงเศษส่วนซ้อนบนป้ายและในแผง |
| `vendor/` | three.js r170 (ไฟล์ในเครื่อง ไม่ต้องใช้เน็ต ยกเว้นฟอนต์ Mitr จาก Google Fonts) |

Dev hook: `window.SR` (state, run, race, store) ใช้สคริปต์ทดสอบได้
