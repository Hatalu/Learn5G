# Learn5G Game Opus: มาตรฐานการสร้างสื่อการเรียนรู้ดิจิทัลแบบมีปฏิสัมพันธ์ระดับประถมศึกษา

คู่มือและมาตรฐานหลักการออกแบบและพัฒนาสื่อการเรียนรู้ดิจิทัล (Digital Interactive Learning Media) ประจำโปรเจกต์ **Learn5G** ซึ่งถอดรหัสความสำเร็จมาจาก **Shape Detective (คดีปริศนาเมืองรูปทรง - คณิตศาสตร์ ป.2)**

---

## 1. ปรัชญาและเป้าหมายสูงสุด (The North Star Pedagogy)

### 1.1 กฎเหล็กของสื่อ (Core Mandate)
> **"เด็กไม่ได้รู้สึกว่ากำลังเรียนบทเรียนที่น่าเบื่อ แต่รู้สึกว่ากำลังเป็นตัวละครหลักที่ผจญภัยหรือไขปริศนา โดยทุกเบาะแสและปฏิสัมพันธ์ที่ค้นพบคือองค์ความรู้แท้จริง"**

- ❌ **ห้ามสร้างสื่อในลักษณะ:**
  - Quiz Website (ตอบถูก-ผิดธรรมดา)
  - Worksheet Online (ใบงานดิจิทัลจำเจ)
  - Slide Presentation Interactive
  - Drag & Drop หรือ Flashcard ธรรมดาที่ไร้การพิสูจน์
- ✅ **ต้องสร้างสื่อในลักษณะ:**
  - **Narrative-Driven Discovery**: การเรียนรู้ขับเคลื่อนด้วยโครงเรื่อง มีเป้าหมาย และมีบริบทแวดล้อม
  - **Every Click has Pedagogical Purpose**: ทุกการคลิกหรือสัมผัสต้องทำหน้าที่ทางการเรียนรู้ ไม่ใช่คลิกเพื่อข้ามหรือเลือกเฉยๆ

### 1.2 วงล้อการเรียนรู้หลัก (Core Learning Loop)
$$\text{Explore} \longrightarrow \text{Observe} \longrightarrow \text{Find Clue} \longrightarrow \text{Compare} \longrightarrow \text{Prove} \longrightarrow \text{Draw/Create} \longrightarrow \text{Solve} \longrightarrow \text{Unlock}$$

### 1.3 กลไกสำคัญ: CLUE → PROOF (เบาะแสสู่การพิสูจน์)
เด็กต้องไม่ได้แค่ "เลือกคำตอบ" แต่ต้อง **"พิสูจน์คุณสมบัติ"** ด้วยตนเอง:
1. **Clue (เบาะแส)**: ได้รับคำให้การหรือหลักฐานเชิงคุณภาพ (เช่น "กุญแจนี้มี 3 ด้านตรง และมี 3 มุมแหลม")
2. **Investigation (การสำรวจ)**: ใช้เครื่องมือเฉพาะทางตรวจสอบชิ้นส่วนในโลกเสมือน
3. **Proof (การพิสูจน์คุณสมบัติ)**:
   - แตะนับด้านทีละด้าน (Highlight เส้นตรง vs เส้นโค้ง)
   - แตะนับจุดยอดทีละมุม (วางหมุดจุดยอด)
   - ทดสอบคุณสมบัติคงที่ (แม้จะหมุน เอียง หรือยืดขนาด คุณสมบัติเชิงคณิตศาสตร์ยังคงเดิม)
4. **Conclusion (การสรุปผล)**: สรุปเป็นความรู้เชิงมโนทัศน์ที่ยั่งยืน (Conceptual Understanding)

## 2. ระบบภาพและงานกราฟิก (Visual Architecture)

### 2.1 100% Procedural SVG & Vector Rendering
- **ความคมชัดอิสระจากความละเอียด**: ใช้ SVG แท้ในการวาดฉาก ตัวละคร และไอเท็มทั้งหมด ทำให้ขยายบนจอแท็บเล็ต จอสัมผัส หรือโปรเจกเตอร์หน้าห้องเรียนได้คมกริบ 100% โดยไม่แตก
- **Zero Asset Drop**: ไม่พึ่งพาไฟล์รูปภาพภายนอกที่อาจโหลดช้าหรือตกหล่น สื่อทำงานได้รวดเร็ว ทำงานออฟไลน์ได้สบาย
- **Storybook / Paper Cutout Aesthetics**:
  - สีพื้นหลังกระดาษอบอุ่น (`--paper: #fdf3dc`, `--paper-2: #f7e6c0`)
  - เส้นขอบหนาสไตล์ภาพประกอบหนังสือนิทาน (`--ink: #3b2a20`, เส้นหนา 3px - 5px)
  - เงาชัดเจนแบบ Flat-Clay Shadow (`box-shadow: 0 5px 0 var(--ink)`)

### 2.2 Character & Persona Design
- **Mentor Character (เช่น ลุงฮูก)**: มีปฏิกิริยาทางอารมณ์ คอยให้กำลังใจ และใช้เทคนิค Socratic Questions (ตั้งคำถามชี้นำ ไม่เฉลย)
- **Player Character (เช่น น้องนักสืบ)**: ตัวแทนเด็ก มีท่าทางตื่นเต้น ดีใจ สงสัย และฉลองความสำเร็จ
- **Antagonist / Mystery Element (เช่น เจ้าขยุกขยิก)**: ตัวสร้างปมปริศนา ไม่น่ากลัว แต่กระตุ้นความท้าทายให้เด็กอยากเอาชนะ

## 3. ระบบเสียง (Sound & Audio Architecture)

### 3.1 WebAudio API Sound Synthesis (Zero-Dependency)
สังเคราะห์เสียงด้วย WebAudio API ผ่าน JavaScript บริสุทธิ์ ปราศจากไฟล์เสียง `.mp3` ภายนอก:
- **Interaction Feedback**:
  - `click`: เสียงป๊อปเบาๆ นุ่มนวล
  - `clue`: คอร์ดกังวาน (Arpeggio triad) เมื่อพบหลักฐาน
  - `count`: เสียงโน้ตไล่ระดับความถี่ (C5 $\to$ D5 $\to$ E5 $\to$ G5 $\to$ A5) เมื่อแตะนับด้าน/มุม
  - `proof`: ฮาร์โมนิกคู่เมเจอร์บ่งบอกว่าพิสูจน์สำเร็จ
  - `unlock`: เสียงกลไกหมุนปลดล็อก
  - `cheer / win`: แฟนแฟร์และเสียงสะท้อนแห่งชัยชนะ
  - `gentle-error`: เสียงโทนต่ำนุ่มนวล ไม่ดุร้าย ไม่ทำให้เด็กรู้สึกกลัวความผิดพลาด
- **Adaptive Ambient Music**: ทำนองดนตรีวนลูปเบาๆ แบบ Playful Mystery สร้างสมาธิและความจดจ่อ

### 3.2 Dual Audio Accessibility (Thai TTS + Speech)
- รองรับ **Web Speech Synthesis API** สำเนียงภาษาไทย
- มีปุ่มลำโพง 🔊 กำกับไว้ที่ข้อความสำคัญ คำใบ้ และบทสนทนา เพื่อให้เด็ก ป.1-ป.3 ที่ยังอ่านหนังสือไม่คล่อง สามารถกดฟังเสียงอ่านได้ทุกที่

## 4. ปฏิสัมพันธ์และ UI/UX สำหรับเด็กประถม (Kid-Centered UI/UX)

### 4.1 Skeuomorphic Toolbelt (แถบเครื่องมือโลกเสมือน)
- จำลองอุปกรณ์เหมือนของจริงในมือนักสืบ/นักสำรวจ:
  - **Shape Lens / แว่นขยาย**: ตรวจจับเส้นตรง เส้นโค้ง นับมุม
  - **Clue Scanner / เครื่องสแกน**: สแกนความหนาแน่นและโครงสร้าง
  - **Shape Pen / ปากกาวิเศษ**: วาดเส้นเพื่อพิสูจน์และเชื่อมต่อรูปทรง
  - **Evidence Bag / กระเป๋าหลักฐาน**: จัดหมวดหมู่ของที่รวบรวมได้
  - **Notebook / สมุดบันทึก**: ทบทวนความรู้ที่สรุปเป็นสมุดภาพ
- **Active Tool Feedback**: ไอคอนเครื่องมือที่เลือกอยู่จะขยับ (Wiggle/Bounce) พร้อมกรอบเรืองแสงสีเหลืองชัดเจน

### 4.2 Lenient Shape Drawing Recognizer (ระบบตรวจจับการวาดที่ยืดหยุ่น)
- สำหรับกิจกรรมเขียน/วาดรูปเรขาคณิต:
  - รองรับการวาดด้วยนิ้วมือหรือเมาส์ที่ไม่ตรงเป๊ะของเด็กประถม
  - ตรวจสอบ:
    1. ความเป็นรูปปิด (Closed loop: จุดเริ่มต้นกับจุดสิ้นสุดใกล้กัน)
    2. สัดส่วนและจำนวนมุมหัก (Corner detection ผ่านมุมเวกเตอร์ $\Delta \theta$)
    3. ความโค้งมนสม่ำเสมอสำหรับวงกลมและวงรี
  - มีระบบ Guide Dot หรือเส้นประโปร่งใสเพื่อช่วยเหลือเด็กที่กล้ามเนื้อมือยังไม่แข็งแรง

### 4.3 Scaffolding & Remediation 3 ระดับ (ระบบคำใบ้แบบไม่เฉลย)
เมื่อเด็กตอบผิดหรือติดขัด:
- **ระดับ 1 (Observe)**: ชี้ชวนให้สังเกตจุดเด่น ("ลองมองดูที่มุมแหลมของรูปนี้สิ")
- **ระดับ 2 (Guide Tool)**: แนะนำให้ใช้เครื่องมือ ("ลองหยิบ Shape Lens มาแตะนับด้านดูนะ")
- **ระดับ 3 (Direct Prompt)**: เพิ่มหมุดนำทางบนภาพ โดยยังคงให้เด็กลงมือกดพิสูจน์ด้วยตัวเอง

## 5. การรองรับ 3 โหมดการใช้งาน (Tri-Mode Architecture)

สื่อการสอนต้องรองรับบริบทห้องเรียนจริง 3 รูปแบบ:

| โหมด | วัตถุประสงค์ | พฤติกรรมของระบบ |
| :--- | :--- | :--- |
| **1. Story / Self-Learning** | สำหรับเด็กเรียนรู้ด้วยตนเองที่บ้านหรือห้องคอมฯ | เล่นตามเนื้อเรื่อง มีการปลดล็อกพื้นที่ทีละด่าน เก็บสะสมกุญแจ/เหรียญรางวัล |
| **2. Free Exploration** | สำหรับเด็กที่ต้องการทบทวนหรือทดลองสร้างสรรค์ | เลือกเล่นพื้นที่ใดก็ได้อิสระ ไม่มีเงื่อนไขการล็อก |
| **3. Teacher Mode** | สำหรับครูนำสอนหน้ากระดานอัจฉริยะ (Smart Board) | ปลดล็อกทุกด่านทันที, มีชุดคำถามชวนคุย (Discussion Prompts), แผนการสอนรายกิจกรรม, และรายงานสรุปผล (Assessment Dashboard) |

## 6. สุขอนามัยของระบบและการรักษาความปลอดภัย (Session & Security)

### 6.1 Fresh Session Reset (เริ่มใหม่ทุกครั้งที่เปิดเล่น)
- สำหรับสื่อเด็กประถมที่ใช้ร่วมกันในโรงเรียน:
  - ทุกครั้งที่เปิดหน้าเว็บใหม่ ระบบต้องล้าง State ชั่วคราวและเริ่มเล่นใหม่ตั้งแต่ต้น (`defState()`) เพื่อให้เด็กคนที่มาใช้เครื่องต่อได้ประสบการณ์การเรียนรู้ครบวงจร
  - มีปุ่ม "เริ่มคดีใหม่ทั้งหมด" อย่างชัดเจน

### 6.2 Central Supabase Auth & Premium Guard
- **Authentication**: เชื่อมต่อผ่าน Supabase Database กลาง (`profiles`)
- **Username Input Placeholder**: ต้องระบุชัดเจนว่า **`ใส่ชื่อที่คุณได้รับมาจากเพจ`**
- **สิทธิ์การเข้าใช้งาน**:
  - `role: 'dev'`: สิทธิ์พัฒนา ไม่จำกัดเวลา
  - `role: 'member'`: ต้องมี `premium_until` ที่ยังไม่หมดอายุ หากหมดอายุหรือเป็น `-` จะแสดงหน้าต่างแจ้งเตือนและระงับการเข้าเล่น
- **User Badge**: แสดงสถานะและชื่อผู้ใช้ทั้งที่หน้า Title และบนแถบ HUD พร้อมปุ่ม Logout

## 7. เช็คลิสต์ตรวจสอบคุณภาพสื่อ (Opus Quality Checklist)

ก่อนส่งมอบหรืออัปเดตสื่อทุกชิ้น ต้องผ่านเกณฑ์ต่อไปนี้:
- [ ] ตัวหนังสือขนาดใหญ่ อ่านง่าย ฟอนต์เป็นมิตร (เช่น Mali, Itim, Prompt)
- [ ] รองรับทั้ง Touch Screen (iPad/Tablet) และเมาส์บน Desktop
- [ ] จอแสดงผล Responsive พอดีหน้าจอ ไม่ต้องเลื่อน (Scroll) ขึ้น-ลง ในฉากเล่นหลัก
- [ ] มีเสียงอ่านภาษาไทย (TTS) กำกับข้อความคำถาม
- [ ] มีกลไกพิสูจน์ความรู้ (CLUE $\to$ PROOF) อย่างน้อย 1 กิจกรรมต่อ 1 มโนทัศน์
- [ ] แก้ไขความเข้าใจผิด (Misconceptions) ที่พบบ่อยในระดับชั้นนั้นๆ ครบถ้วน
- [ ] มี Teacher Mode พร้อมคำถามชวนคิดสำหรับครู
- [ ] รันบน Local Server และมีระบบเชื่อมต่อ Supabase ถูกต้อง
